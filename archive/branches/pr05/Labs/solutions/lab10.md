## M10-C2. Совмещение скрыло неправильное размещение

Жёсткое совмещение удалило бы именно проверяемую ошибку размещения.


```python
case_input = {'translation_angstrom': [5, 0, 0], 'reference': 'docking/1iep_ligand.pdbqt', 'official_pose': 'docking/1iep_ligand_vina_out.pdbqt'}
from docking import first_pose,mapped_rmsd
a,_=first_pose(DATA/case_input['reference']); x=np.array([a[k] for k in sorted(a)]); shift=np.array(case_input['translation_angstrom']);answer={'same_reference':0.,'translated':float(np.sqrt(np.mean(np.sum((x-(x+shift))**2,axis=1)))),'official_prepared':mapped_rmsd(DATA/case_input['reference'],DATA/case_input['official_pose'])}
```


Ожидаемый численный контракт: `{"same_reference": 0, "translated": 5, "official_prepared": 0.906728765427707}`.
