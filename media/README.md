# Медиа курса

`images/` — изображения и фотографии с источником и правами; `infographics/` — авторские схемы; `video/` — будущие видео, если они решают конкретную учебную задачу. Пустой раздел не считается созданным медиаматериалом.

В новой вводной связке изображения молекул строятся кодом Notebook, график HPLC — кодом тренажёра и прямо обозначен как условный. Сторонние книги и их иллюстрации не публикуются автоматически. Видео на этом этапе не создаются.

Для нового файла нужен паспорт: автор/источник, лицензия, изменения, назначение в уроке, альтернативное текстовое описание. Нельзя использовать условный рисунок как доказательство экспериментального результата.
