## M08-C1. Контрольная пластина стала шумной

Контроль распределений, качество ранжирования и химический риск измеряют разные вещи.


```python
case_input = {'mu_pos': 100, 'mu_neg': 10, 'sd_good': [5, 5], 'sd_bad': [20, 20], 'N': 1000, 'A': 20, 'k': 50, 'a': 5}
z=lambda s:1-3*sum(s)/abs(case_input['mu_pos']-case_input['mu_neg']);answer={'z_good':z(case_input['sd_good']),'z_bad':z(case_input['sd_bad']),'ef':(case_input['a']/case_input['k'])/(case_input['A']/case_input['N'])}
```


Ожидаемый численный контракт: `{"z_good": 0.6666666666666666, "z_bad": -0.3333333333333333, "ef": 5}`.


## M08-C2. Нельзя выкинуть все предупреждения

PAINS — предупреждение, eligible — вычислительный статус; ни один не является доказанной активностью.


```python
case_input = {'smiles': ['Oc1ccccc1O', 'CCO', '']}
from chemistry import screen
answer={'statuses':[screen(s)['status'] for s in case_input['smiles']]}
```


Ожидаемый численный контракт: `{"statuses": ["review", "eligible", "invalid"]}`.
