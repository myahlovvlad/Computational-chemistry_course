# Модель покрытия и химического расстояния

Morgan radius 2, 2048 bits с chirality задаёт конкретное представление. Для бинарных fingerprints Tanimoto=|A∩B|/|A∪B|. Ближайший сосед ищется только в training; совпадение query с собственной строкой не является проверкой переноса. Murcko-группы объединяют стереоизомеры; для ациклических молекул применяется generic topology полного графа.

Calibration и test различны. В calibration каждый каркас даёт score=max|y−ŷ| по его соединениям. При m группах берётся порядок ceil((m+1)·(1−α)); если такой порядок превышает m, конечный интервал не объявляется. Здесь α=.1. При обменности групп это даёт групповую интерпретацию; химический или временной domain shift нарушает предпосылку.

На test отдельно вычисляем долю покрытых соединений и долю каркасов, для которых покрыты все соединения. Их нельзя смешивать. Наблюдаемое покрытие 95.43% соединений и 91.18% из 363 каркасов не гарантирует того же для новых лекарственных рядов. Ширина интервала не учитывает автоматически все систематические неопределённости.

Источники: [ChEMBL API](https://www.ebi.ac.uk/chembl/api/data/docs), [RDKit fingerprints](https://www.rdkit.org/docs/GettingStartedInPython.html). Точный алгоритм и assumptions записаны в `scripts/train_target_qsar.py`; сохранённый аудит проверяет split, наблюдения, метрики и query exclusion.
