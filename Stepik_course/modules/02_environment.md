# Модуль 2. Цифровой верстак: от установки к первому проверенному результату

**Автор / аффилиация:** заполняются автором курса. **Время:** 5 часов. **Задача:** запустить небольшой расчёт и уметь восстановить среду.

**Аннотация.** Нестабильное окружение способно остановить работу раньше химии. Мы разделяем интерпретатор, среду и рабочую папку, осваиваем минимальный Python и запускаем RDKit. ИИ используется как помощник по объяснению ошибок с обязательной проверкой. Итог — первый отчёт и паспорт среды.

**План:** терминал → среда → Python → проверка. **Путь:** от «я химик, а не программист» к самостоятельной диагностике запуска. **Результаты:** различить файл и команду; обработать список значений функцией; воспроизвести запуск и объяснить ошибку.

## 2.1. Где работает программа

Сбой установки не говорит о ваших способностях к химии. Чаще программа запущена другим Python или из другой папки. Терминал — способ передать команду; интерпретатор исполняет Python; редактор меняет текст. Виртуальная среда — отдельная полка реагентов, но она не изолирует всё устройство и не заменяет операционную систему.

В Windows используйте PowerShell и `python --version`; если команда отсутствует, сначала установите поддерживаемый Python с официального сайта. Для Linux/macOS имя команды может быть `python3`. Не копируйте команду вместе с приглашением терминала. Путь с пробелами берите в кавычки.

## 2.2. Первый запуск

В корне учебного проекта выполните:

```powershell
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r Stepik_course/practice/requirements.txt
.venv\Scripts\python.exe Stepik_course/practice/chemistry.py
```

Для Linux/macOS после `python3 -m venv .venv` используйте `.venv/bin/python`. Активация среды не обязательна: явный путь уменьшает путаницу. Пакеты требуют доступа к сети при установке; автономный запуск возможен после подготовки зависимостей.

| Среда | Когда выбирать | Ограничение |
|---|---|---|
| Нативный Python/RDKit | Первые химические практики | Не все сторонние инструменты имеют сборку под вашу ОС |
| WSL 2 | Linux-инструмент на Windows | Стандартная установка требует прав администратора; используется Linux-ядро в VM |
| Готовые результаты | Тяжёлый факультатив недоступен | Нужно проверять протокол и интерпретацию, самостоятельный расчёт пока не выполнен |

Linux устанавливают под конкретную задачу. Он не является условием понимания графа молекулы.

## 2.3. Python для химика

```python
def to_molar(value: float, scale: float) -> float:
    # WHY: логарифм концентрации требует единой системы единиц.
    return value * scale

values = [10.0, 100.0, 1000.0]
result = [to_molar(value, 1e-9) for value in values]
print(result)
```

Разберите список, цикл, функцию, аргумент и возвращаемое значение. Затем замените одно число на строку и прочитайте traceback снизу вверх. Не исправляйте ошибку случайным удалением строк.

**Быстрый результат:** выполнить первые ячейки `quickstart.ipynb` или `chemistry.py` на готовом учебном вводе. Пять минут отсчитываются после готовности среды; установка в это обещание не входит.

## 2.4. ИИ как проверяемый лаборант

Рабочий запрос: «Вот код, версия библиотеки и traceback. Объясни причину. Предложи минимальное исправление и проверку на валидной записи, пустом вводе и контрпримере». Сначала прочитайте исправление, затем запустите тест. Облачный помощник не нужен для сдачи. Локальная модель требует собственных ресурсов; слово «локальная» не гарантирует, что она установлена.

**Практика:** дописать `to_molar`, обработать список и записать версии. Три проверки: `100 нМ → 1e-7 М`; неверная единица вызывает явную ошибку; повторный запуск создаёт такой же химический результат. Полный код и тесты — в `practice/`.

**Контроль.** «RDKit установлен, но import падает в ноутбуке». **Ответ:** проверить интерпретатор ядра, а не переустанавливать ОС. «WSL 2 — перевод Linux-команд в Windows?» **Ответ:** нет, там реальное ядро Linux. «Можно ли сдать курс без ИИ?» **Ответ:** да.
