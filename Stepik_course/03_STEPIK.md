# Перенос в Stepik: уроки, шаги и проверка

**Назначение:** инструкция автору для сборки курса. **Статус:** редакторский пакет, без публикации и доступа к аккаунту. **Дата проверки документации:** 10.11.2026.

## 3.1. Как разрезать тексты

В Stepik курс состоит из модулей, модуль — из уроков, урок — из шагов. Создайте 14 модулей и по четыре урока из таблицы программы. Нумерованные разделы файлов `modules/` — основные тексты этих уроков. Паспорт показывается в начале модуля; не нужно повторять полный Abstract на каждом коротком шаге [1].

**Обычный урок:** короткая ситуация и вопрос-прогноз → текст с одной основной идеей → разобранный пример → задача → объяснение правильного и типового ошибочного решения. Не дублируйте один длинный текст и длинное видео; видео заменяет объяснение там, где пространственный процесс трудно показать статично. Примерная длина текстового шага — 150–350 слов, но сложность важнее механического лимита.

У каждого модуля предусмотрены три контрольных вопроса. Разместите их в соответствующих уроках; после неверного ответа покажите объяснение из текста и контрпример. Четвёртый урок объединяет практику и самопроверку. Дополнительные вопросы по отдельным урокам стоит добавлять после пилота, если обнаружатся новые устойчивые ошибки.

## 3.2. Какие форматы использовать

| Результат обучения | Реализация | Пример |
|---|---|---|
| Различить понятия | Один/несколько правильных вариантов | Канонизация строки и таутомера |
| Восстановить процесс | Сортировка/сопоставление при наличии формата в редакторе | raw → проверка → политика → отчёт |
| Посчитать показатель | Численный ответ с допуском | pIC50, Z′, EF |
| Написать небольшую функцию | Программирование на стандартном Python | Танимото без RDKit |
| Обработать молекулы | Локальный notebook + контрольный вопрос/данные | Соль и ковалентный Cl |
| Оценить обоснование | Рубрика, взаиморецензирование или преподаватель | Почему нельзя закупать по score |

Официальные материалы Stepik описывают разные форматы шагов [2]. Не рассчитываем, что RDKit установлен в стандартном проверяющем Python. Нужный набор библиотек и доступные режимы проверки подтверждают в тестовом курсе. Базовый вариант здесь: химия выполняется локально, Stepik проверяет числа, понятия и небольшие функции без внешних пакетов.

External grader, LTI, проверка преподавателем и некоторые операции с файлами зависят от доступного режима/тарифа. Это опции развития после проверки аккаунта, а не обязательное условие первого запуска [3]. Внешнее приложение с вводом данных не отправляет оценки в Stepik автоматически. Прямая вставка произвольного JavaScript/iframe в текстовый шаг не предполагается: сначала проверьте редактор; надёжный fallback — ссылка и отдельный проверочный вопрос.

## 3.3. Четыре готовых программных задачи

Эталоны — `practice/stepik_tasks.py`. При переносе оформите каждую как отдельную задачу. Для самого простого варианта студент пишет программу stdin → stdout; функции ниже могут быть эталонными решениями автора.

**P1, модуль 7.** На вход одной строкой положительное число и единица `M/mM/uM/nM`. Вывести `−log10(value*scale)` с шестью знаками. В этой задаче вход гарантированно валиден; отдельная задача учит обработке ошибок.

- Вход `100 nM`, выход `7.000000`.
- Вход `0.1 uM`, выход `7.000000`.
- Вход `1 mM`, выход `3.000000`.
- Скрытый тест `2 M` → `-0.301030`. Не ограничивать ответ неотрицательными значениями.

**P2, модуль 5.** Даны две строки номеров активных битов через пробел. Пустая строка означает пустое множество. Повторы игнорируются. Вывести Танимото с шестью знаками, для двух пустых множеств принято 1.

- `1 2 3` / `2 3 4` → `0.500000`.
- `1 1` / `2` → `0.000000`.
- две пустые строки → `1.000000`.
- Скрытый тест на перестановку строк проверяет симметрию.

**P3, модуль 8.** На вход N, A, k, a: размер библиотеки, число активных, размер top-k, число активных в нём. Счётчики согласованы, A>0. Вывести EF@k с шестью знаками.

- `1000 20 50 5` → `5.000000`.
- `100 10 10 0` → `0.000000`.
- `100 10 100 10` → `1.000000`.

**P4, модуль 8.** На вход μpos, μneg, σpos, σneg. Средние различаются, σ≥0. Вывести Z′ с шестью знаками.

- `100 10 5 5` → `0.666667`.
- `10 100 5 5` → `0.666667`.
- `100 10 20 20` → `-0.333333`.

Числа лучше проверять с абсолютным допуском 1e−5. Публичные тесты учат формату, скрытые проверяют контрпримеры. Текущий пакет содержит эталонные функции и тесты локально, а не готовые API-объекты импорта Stepik.

## 3.4. Проверка локальных практик

Не используйте вопрос «нажали ли вы кнопку?» как подтверждение навыка. После запуска студент отвечает, почему Cl сохранился, где число стало логарифмом и что означает статус `review`. Одно число из заранее известного CSV легко списать; для более сильной проверки выдайте вариант структуры и попросите короткое обоснование. Не делайте оценку зависимой от случайного численного результата стохастического поиска без допусков.

Перед публикацией: пройти курс отдельным тестовым учеником; проверить ссылки и мобильный текст; убедиться, что вводные практики обходятся без специального железа; выполнить численные задачи в реальном grader; выбрать режим итоговой оценки и явно описать его; загрузить видео с субтитрами и текстовой альтернативой. Статусы факультативов, число баллов и сертификат нужно настроить вручную.
