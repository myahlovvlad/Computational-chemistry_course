Нарратив ведёт от лабораторного решения к неопределённости и обратно. Учебная сцена не приписывается авторам статьи; научная новизна оригинала отделена от задачи учебной адаптации. Прямые первичные источники: [Delaney](https://pubmed.ncbi.nlm.nih.gov/15154768/), [DeepChem CSV](https://github.com/deepchem/deepchem/blob/455d07f3e17e880a4d980b5b0365e4a02b417e14/datasets/delaney-processed.csv), [IUPAC: растворимость](https://goldbook.iupac.org/terms/view/S05740/1000), [Daylight: SMILES](https://www.daylight.com/dayhtml/doc/theory/theory.smiles.html), [PDB 1HWK](https://www.rcsb.org/structure/1HWK). Библиография присутствует в самих книгах.

[Математический протокол](MATHEMATICAL_PROTOCOL.md) фиксирует определения и ограничения. Кратность 10 / τ = 1 введена как явно учебный ориентир, не норматив качества вещества или критерий статьи. Полученная в guided доля в пределах ориентира — 0.7340425531914894; 75 из 282 записей за ним. Это описание архива, не оценка вероятности будущего успеха. Исходные MAE/RMSE и химические значения не изменялись.

[Карта педагогических вопросов](PROMPT_DESIGN.md) связывает каждый prompt с ожидаемым рассуждением, типичной ошибкой и обратной связью. Для P04/P06/P09 реализована обратная связь по вариантам; пустой выбор — NOT_RUN, правильный — COMPONENT_CORRECT только для данного компонента. Свободное объяснение и перенос автоматически не оцениваются.

## Фактическая проверка новой версии

На Windows 10 / Python 3.12.10 и Ubuntu/WSL / Python 3.12.3 в прежних отдельных uv-средах без RDKit:

- **14 unit tests PASS** на каждой ОС, включая отсутствие ответа, раздельную обратную связь для типичных ошибок и обработку недопустимого выбора.
- **Guided PASS:** исполнены все ячейки; встроены оба фактических графика; сохранены вычисления, учебный критерий и незаполненный личный журнал.
- **Independent scaffold PASS:** выполнена только подготовка шаблона; все три решения студента NOT_RUN.
- **Instructor C1/C2 PASS:** эталоны пересчитаны, добавлена доля в пределах того же учебного ориентира; C3 остаётся планом для содержательной оценки.

Точные argv, версии, SHA256 новых входов, stdout/stderr и исходные/исполненные книги: [Windows](evidence/windows-20261117-context/summary.json), [Linux](evidence/linux-20261117-context/summary.json). В `inputs.json` теперь включены авторские Markdown, словарь, математический протокол, педагогическая карта и код обратной связи. Старые запуски сохранены отдельно; [реестр проверок](practice-checks.csv) содержит столбец revision.

[Точные исходные байты новой проверки](evidence/context-source-inputs/sources.json) сохранены отдельно и сверены с input SHA256 обеих ОС. Это позволяет проверить исходники, даже когда Git нормализует окончания строк обычных текстовых файлов. Полная новая копия CSV в архив не добавлена; его закреплённый официальный источник и hash остались прежними.

При проверке HTML обнаружено, что прежние разделители формул теряли часть TeX-разметки. Исходники переведены на `$`/`$$`, после этого обе книги исполнены повторно. [Проверка представления](evidence/presentation/review.json) проверяет локальные ссылки, встроенные PNG и сохранность формул при экспорте HTML. Она не является проверкой браузерного typesetting или педагогической эффективности. Текстовые объяснения к графикам есть; автоматический HTML-экспорт сообщает об отсутствии отдельного alt-текста PNG.

Для повторения: команды среды в [README](README.md#окружение), `run_checks.py` с новым output-каталогом; целостность опубликованных captures — `python course_source/modules/M01/verify_evidence.py`. Авторские тексты и код собираются генератором, а не редактируются независимо в двух представлениях.
