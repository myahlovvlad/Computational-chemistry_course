# Дополнение к ЛР 12: пакетный DFT

[Рабочий notebook](dft_pyscf.ipynb) вызывает `Labs/pyscf_dft.py` и выполняет RHF/STO-3G и PBE/STO-3G для H2 при одинаковой геометрии. Метод, базис и функционал выводятся раздельно. Это single-point, не оптимизация и не термохимия.

PySCF [не поддерживается нативно в Windows](https://pyscf.org/user/install.html). Для Linux/macOS/WSL создайте отдельную среду и установите PySCF по официальной инструкции. Эта дополнительная среда в текущей работе не разворачивалась; notebook **не входит в число 14 проверенных запусков**. Никакое значение DFT не подставлено как якобы вычисленное.

Основной notebook ЛР 12 выполняет самостоятельный RHF на NumPy/SciPy и проверен на Windows. Дополнение показывает работу реального пакетного DFT; после собственного запуска студент должен приложить версии, сходимость, сетку и полученный JSON. Сначала сопоставьте HF-контроль −1,1167593 Hartree, затем изучите разницу методов. Не требуйте равенства HF и DFT и не интерпретируйте её как барьер.
