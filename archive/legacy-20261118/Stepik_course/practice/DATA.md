# Паспорт учебных данных

Оба CSV созданы специально для курса 10.11.2026. Это искусственные записи. Структуры соответствуют простым химическим примерам; все числа активности вымышлены. `T1`, `T2`, `A1`, `A2` — условные идентификаторы. Имена молекул используются как учебные подписи, не как идентификаторы источника.

`molecules.csv` проверяет одинаковые графы, соль/кислоту, ковалентный Cl, стереопару, пустой и неверный ввод. Объединение натрий ацетата с уксусной кислотой — только политика parent для вычисляемых признаков, не разрешение объединять их измеренные свойства.

`activities.csv` проверяет единицы, тип endpoint, знак отношения, мишень и ассей. R01/R02 дают pIC50=7 и являются учебными повторами, а не независимыми измерениями. Пример не содержит условий эксперимента, поэтому не может служить исследовательским датасетом даже после фильтрации.

В `screen` используются только PAINS и четыре условия учебного Ro5. Это не полный токсикологический фильтр. `eligible` означает отсутствие перечисленных предупреждений, не рекомендацию синтеза/закупки.

Для ESOL нужно отдельно скачать открытый набор по ссылкам MoleculeNet, проверить лицензию, сохранить дату и SHA256, выбрать измеренный target и исключить готовый рассчитанный прогноз ESOL из признаков. Искусственные CSV не подходят для оценки качества QSPR.
