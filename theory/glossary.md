# Словарь курса

Возвращайтесь к словарю по мере исследования. Совпадение аббревиатуры не гарантирует совпадение величины или метода.

| Термин | Полная форма и смысл |
|---|---|
| CID | Compound Identifier, идентификатор записи PubChem; не номер атома и не паспорт экспериментального образца |
| SMILES | Simplified Molecular Input Line Entry System, строковая запись молекулярного графа |
| InChI / InChIKey | International Chemical Identifier / поисковый ключ; отражают выбранный стандарт идентичности |
| Канонизация | Выбор стандартной записи заданного графа; не доказательство одинакового физического образца |
| Стереохимия | Пространственная конфигурация, которую можно потерять при упрощении строки |
| E/Z | Описание конфигурации двойной связи по правилам приоритетов; не равно R/S |
| R/S | CIP-дескрипторы стереоцентров; при изменении окружения атома нужно повторно проверять соответствие |
| CIP | Cahn–Ingold–Prelog, система приоритетов для стереохимических дескрипторов |
| M / Mr / MolWt | M — молярная масса в g/mol; Mr — безразмерная относительная молекулярная масса. Дескриптор RDKit MolWt используется здесь как численное значение средней молярной массы выбранной записи; соль и активный фрагмент не взаимозаменяемы |
| logP / logD | Распределение нейтральной формы / суммарное распределение форм при заданных условиях; не одно и то же |
| TPSA | Topological Polar Surface Area, топологическая полярная поверхность, расчётный дескриптор |
| HBD / HBA | Hydrogen-Bond Donors / Acceptors, счётчики донорных и акцепторных центров по заданному алгоритму |
| logS | В этом курсе log10(S/(1 mol/L)); всегда проверять определение конкретного источника |
| QSPR / QSAR | Quantitative Structure–Property / Structure–Activity Relationship: модель свойства / активности; endpoint должен быть определён |
| MAE / RMSE | Средний модуль ошибки / корень средней квадратической ошибки; относятся к указанной шкале и выборке |
| MM / MMFF | Molecular Mechanics / Merck Molecular Force Field; силовое поле не решает электронную задачу |
| ETKDG | Experimental-Torsion Knowledge Distance Geometry, способ генерации исходных конформеров |
| SCF | Self-Consistent Field, самосогласованное поле; остановка по сходимости не подтверждает пригодность физической модели |
| RHF | Restricted Hartree–Fock, ограниченный метод Хартри–Фока |
| DFT / TDDFT | Density Functional Theory / Time-Dependent DFT, приближения для основного / возбуждённых состояний |
| Базис | Набор функций представления электронных орбиталей; название и версия важны для воспроизводимости |
| UV–Vis / ИК | Ультрафиолетовая и видимая / инфракрасная спектроскопия; разные диапазоны и физические переходы |
| FWHM | Full Width at Half Maximum, ширина на половине высоты; не ширина пика у основания |
| HPLC / UHPLC | Высокоэффективная / ультравысокоэффективная жидкостная хроматография |
| PDA / DAD | Фотодиодноматричный детектор; многоволновой отклик не равен однозначной идентификации вещества |
| tR / Rs | Время удерживания / разрешение пары пиков; нужны совместимые определения ширин и единиц |
| DOE | Design of Experiments, планирование эксперимента; изменение одного фактора не выявляет все взаимодействия |
| A2A | Подтип аденозинового рецептора; наличие структуры комплекса не доказывает проникновения через ГЭБ |
| CNS / ЦНС | Central Nervous System, центральная нервная система |
| BBB / ГЭБ | Blood–Brain Barrier, гематоэнцефалический барьер |
| HMGCR | Символ гена HMG-CoA-редуктазы; в тексте нужно различать ген и белок-фермент |
| OATP | Organic Anion Transporting Polypeptide, семейство транспортёров; не синоним мишени аторвастатина |
| GalNAc | N-acetylgalactosamine; в системе доставки имеет собственную роль, отличную от груза siRNA |
| ASGPR | Asialoglycoprotein Receptor, рецептор клеточного захвата, не конечная мишень PCSK9 |
| siRNA / PCSK9 | Малая интерферирующая РНК / proprotein convertase subtilisin/kexin type 9; этапы доставки и действия не смешиваются |
| SHA256 | Контрольная сумма байтов файла; не проверка химической истинности |
| CSV / JSON | Табличный / структурированный формат; единицы и происхождение должны быть заданы отдельно |
| API / CLI / IDE | Программный интерфейс / командная строка / среда разработки; это инструменты, а не химические модели |
| PASS / FAIL | Проверка выполнена успешно / неуспешно в явно указанном объёме |
| BLOCKED / NOT_RUN | Проверка заблокирована ресурсом / не выполнялась; не выдавать эти статусы за успех |

Источники терминов: [Daylight SMILES](https://www.daylight.com/dayhtml/doc/theory/theory.smiles.html), [IUPAC Gold Book](https://goldbook.iupac.org/), [PubChem](https://pubchem.ncbi.nlm.nih.gov/), [RCSB](https://www.rcsb.org/), документы конкретных методов в уроках. Единицы и определения первоисточника имеют приоритет над кратким пояснением словаря.
