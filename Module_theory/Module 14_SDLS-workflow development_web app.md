# Модуль 14. Передача инструмента: от рабочего ноутбука к воспроизводимому решению

**Автор / аффилиация:** заполняются автором курса. **Время:** 8 часов. **Задача:** дать коллеге инструмент и достаточно информации, чтобы проверить результат.

**Аннотация.** Ноутбук, работающий только у автора, трудно использовать повторно. Мы отделяем химические функции от интерфейса, проектируем CLI и страницу Streamlit, проверяем вход и сохраняем журнал. Итоговый проект объединяет базовые навыки курса. Студент защищает решения и ограничения, а не количество установленных библиотек.

**План:** ядро → интерфейс → воспроизводимость → защита. **Путь:** от «на моём компьютере работает» к проверяемой передаче. **Результаты:** описать контракт данных; обработать ошибку без потери строки; защитить отчёт по рубрике.

## 14.1. Контракт функций

Коллега принёс CSV с пустой ячейкой. Если приложение падает целиком или молча удаляет строку, проблему нельзя исправить красивой кнопкой. Функция стандартизации принимает одну структуру и выдаёт документированный результат. Табличный слой сохраняет ID. Интерфейс показывает результат, а не меняет химическую политику незаметно.

CLI — Command-Line Interface, интерфейс командной строки — удобен для воспроизводимых пакетных запусков. Веб-интерфейс удобен для разовой работы коллеги. Оба вызывают одно ядро; тесты проверяют ядро на химических контрпримерах.

## 14.2. ТЗ на локальное приложение «Химера»

Поля: CSV со столбцами `id,smiles`, название политики, переключатель таутомерной обработки с пояснением. Действие: рассчитать. Выход: таблица raw/parent, дескрипторы, предупреждения и статусы; счётчики; полный CSV для скачивания; паспорт запуска. Предел размера файла и числа структур указывается пользователю заранее.

| Состояние | Что видит пользователь |
|---|---|
| Пустой ввод | Понятную инструкцию и пример |
| Ошибка одной записи | Причину в строке, остальные результаты сохранены |
| PAINS-предупреждение | «Требуется разбор», описание паттерна |
| Успешный расчёт | Факт вычисления и ограничение интерпретации |

При изменении файла или политики старый результат должен быть явно сброшен или помечен как относящийся к предыдущему вводу. Рабочий пример Streamlit находится в Labs/app.py; студент расширяет и защищает собственную версию. Работающий браузерный тренажёр в `media/` решает отдельные учебные задачи.

## 14.3. Паспорт запуска

Записываем версии Python/RDKit, параметры, seed для стохастических шагов, hash входа, дату, число записей и правила обработки. Для чтения CSV не нужна ML-модель. Для ML-режима отдельно указываем версию признаков, split, проверку применимости и карточку модели. Не обещаем «готово к ML» по одному успешному парсингу.

**Быстрый результат:** другой студент запускает `chemistry.py` и объясняет один статус по журналу. Затем меняет одну входную структуру и подтверждает, что отчёт пересчитан.



## 14.4. Граница между ядром и интерфейсом

Вернёмся к исходной задаче лаборатории. Коллега приносит таблицу, а не готовый Python-объект. Значит, нужно договориться о столбцах, типах, кодировке и ошибках. Входной контракт проверяется до расчёта; химическая функция проверяет структуру; интерфейс сообщает результат. Если все три слоя смешать в одной кнопке, тест становится зависимым от внешнего вида страницы.

В пакете `Labs/chemistry.py` содержит операции над одной молекулой, `Labs/pipeline.py` — табличный конвейер, `Labs/app.py` — локальный Streamlit-интерфейс. CLI и приложение вызывают одно ядро. Коллега получает один полный отчёт со всеми ID, а не только список прошедших. Это защищает воспроизводимость и упрощает обсуждение спорного решения.

## 14.5. Отчёт должен объяснять преобразование

Hash фиксирует байты входного файла. Версия политики фиксирует логику обработки. Версия библиотеки фиксирует исполнителя. Эти три вещи не заменяют друг друга. Если изменилось правило таутомеризации, одинаковый вход способен законно дать другой parent; в отчёте должна быть причина изменения.

Для повторяемой передачи полезен тест «чистая среда → установка → запуск → контрольный отчёт». Предварительно выполненный notebook сохраняет наблюдение автора, но не доказывает, что коллега сможет его повторить. Поэтому в репозитории есть исполняемые исходники, datasets с паспортами и команда проверки. В отчёте отдельно указываем трудоёмкость установки, время ядра и время пользователя.

## 14.6. Защита результата как научный разговор

Правила ясного объяснения из B07 помогают сформулировать вывод: один вопрос, один наблюдаемый результат, одно существенное ограничение и следующее действие [B07, PDF 103–104]. Отчёт «программа успешно отработала» слишком слаб. Отчёт «две записи не читаются, один мотив требует контроля, исходные строки сохранены» уже позволяет принять решение.

На защите предложите другой набор и попросите объяснить один неожиданный статус. Затем спросите, что потребуется для нового endpoint. Если студент отвечает «поменять название колонки», значит, научный контракт не усвоен. Если он перечисляет измерения, признаки, split и контроль применимости, вычислительная логика отделена от конкретного скрипта. Это и есть конечная цель курса: способность отвечать за вывод, а не только нажимать Run All.


## 14.7. Защита и рубрика

Сдать исходный CSV, код, зависимости, таблицу результатов и отчёт. Допустим CLI с отчётом вместо Streamlit, если цель передачи коллеге достигнута; наличие веб-интерфейса не заменяет научную валидацию.

Из 30 баллов проекта: 6 за происхождение и сохранение данных; 6 за химическую политику и проверки; 6 за независимую оценку модели/корректное ограничение немодельного режима; 6 за объяснимые решения; 6 за воспроизводимую передачу. Для проекта без ML проверка независимости заменяется контрольными примерами с известным результатом; в отчёте прямо написано, что прогноз свойства не строился.

Три обязательные демонстрации: валидная структура; неверный ввод; химический контрпример — соль против ковалентного галогена. Задание «скелет» предлагает дописать обработку ошибки и экспорт, самостоятельная часть требует защитить собственную политику.

**Контроль.** «Красивый интерфейс компенсирует утечку?» **Ответ:** нет. «Можно отдать только CSV без политики?» **Ответ:** результат трудно воспроизвести и оценить. «eligible означает рекомендацию к закупке?» **Ответ:** лишь допуск к следующему вычислительному/экспертному этапу.
