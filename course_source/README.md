# course_source — канонические исходные материалы курса

**Основание:** Grill Me, решение 6.1=C (2026-11-16).
**Состояние:** архитектурный каркас, не готовый опубликованный набор уроков. Содержательная миграция ещё не произведена.

Цель: один платформонезависимый источник для Stepik, самостоятельного интерактивного веб-курса, видео и текстовых публикаций. Перенос выполняется **только после проверки практикумов и эталонов** согласно [реестру](../Stepik_course/12_PRACTICE_FIRST_GATE.md). Не считать этот пустой каркас основным текстом курса вместо существующих модулей.

## Проектируемая структура

```text
course_source/
  README.md
  curriculum/         # outcomes, предпосылки, карта модулей, рубрики
  modules/
    <stable_module_id>/
      manifest.yaml    # результаты, термины, ссылки, prerequisite, version
      lessons/
        <lesson_id>.md # один смысловой источник теории
      exercises/
        <exercise_id>.yaml  # вход, эталон, ошибки, тесты, feedback, rubric
      assets/           # лицензированные оригинальные исходники визуализаций
  concept_map/          # словарь узлов, семантика связей, эталоны и задания
  assessments/          # cross-module tests, transfer tasks, итоговое досье
  sources/              # ссылки/библиография/отметки научной проверки
  exports/              # сгенерированные Stepik/web/video артефакты, не редактировать вручную
```

Перечень папок — проект целевого устройства, они появятся при миграции; сейчас существует только README.

## Инварианты

1. У каждой проверяемой задачи стабильный `exercise_id`, а у компетенции `outcome_id`.
2. Готовность материалов определяется доказанной корректностью практикума и анализа ошибок; объяснение подстраивается под них, но обязано оставаться научно верным.
3. Учебный пример имеет происхождение, численные единицы, реальные/синтетические метки и ограничения. Тесты не хранить только внутри повествовательного Markdown.
4. SVG/видео описывают содержательный и проверенный научный механизм; сценарий не становится источником численных истин.
5. Каждый узел/ребро карты либо является проверенным примером, либо явным вопросом на самостоятельное обоснование.
6. `Stepik_course/modules/` и `Module_theory/` — исходники для бережной миграции, но не два параллельно изменяемых канона после принятия конкретного перенесённого урока.
7. Рендеры Stepik, HTML и медиа генерируются из исходников и не должны расходиться в определениях, формульных единицах, ответах и версиях.

## Контракт минимального производственного цикла

**Эталонная задача и рубрика** → тест научного смысла, единиц, ошибок и edge cases → техническая проверка → карта ошибок студента → адаптированная теория → короткие проверяемые упражнения и продуманные медиа → concept-map relation → пакет конкретной платформы → пилот.

## Что не сделано

Нет полной миграции всех 14 модулей, генератора экспорта, готовых справочников связей, экспериментально проверенных задач по всем модулям, проверенного Stepik grader и выпущенного интерактивного редактора карты. Не объявлять наличие README подтверждением соответствия этим требованиям.
