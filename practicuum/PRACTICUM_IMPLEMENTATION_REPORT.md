## Что можно открыть сейчас

Подготовлены M01-L01 (предметное введение, пять коротких MD-шагов), M03-L01 (идентичность и потеря стереохимии), M03-L02 (изомеры, компоненты соли, кислота/лактон). Для каждого есть теория, разбор A, лабораторная B и преподавательская рубрика; для вычислительных лабораторных M03 — исполняемые ориентиры ответа. Код сопровождается русскими пояснениями смысла и нового синтаксиса.

Разборы A используют истрадефиллин/ксантины; перенос B — аторвастатин. Досье одно на весь курс, имеет девять разделов и файловую концептуальную карту; повторная инициализация сохраняет ранее написанное. Пустой `answer=None` получает NOT_RUN; заполненный ответ требует предметного рассмотрения, а не проверки ключевых слов.

HPLC-тренажёр — работающий [прототип](../web-training/trainers/hplc/index.html) с [явной спецификацией](../web-training/trainers/hplc/SPECIFICATION.md). Сохранены 20 экспериментальных строк и отдельная собственная регрессия; сигнал, ширины и перенос промежуточных пиков условны. Для pH/колонки/режима вне исходных условий нет численного прогноза. Давление и полное время цикла не выдуманы. Экспорт в JSON сохраняет попытку/интерпретацию для досье, не оценивает её научное качество.

## Научные границы

Структуры 8RW0/1HWK не устанавливают ГЭБ/печёночную экспозицию. Данные ChEMBL — первые 100 записей на объект, не полный корпус; номер выпуска не получен (status endpoint HTTP 500). Однажды полученный неверный PMCID отклонён по несовпадению DOI; [запись ошибки и исправления](shared/data/source-audit.json) сохранена. Успешный HTTP-ответ не выдаётся за проверку статьи.

HPLC-регрессия заново подогнана по полному квадратичному плану. RMSE подгонки 0,12435/0,16727 мин — ошибка на тех же 20 опытах, не независимая точность. Таблица не содержит числовых сырых хроматограмм и ширин у основания; условный Rs не объявляется экспериментальным или валидацией по ICH.

Новый redocking комплексов истрадефиллин/A2A и аторвастатин/HMGCR не выполнен. Регрессия по готовой позе 1IEP — отдельный контроль. Для публикации M11 нужны подготовка координат/лигандов, настоящий запуск Vina и геометрическая проверка. Три собственных PySCF-расчёта завершены и сохранены с журналами; их ограниченный газофазный протокол не объявляется экспериментальной UV-валидацией или готовыми уроками M07/M08. Windows-уроки не объявляются native PySCF-запусками.

NIST IR raw остаётся локальным cache с ограничениями распространения; лицензия статьи/данных не переносится на чужую библиотеку. Паспорта новых источников — [SOURCES_V2](shared/data/SOURCES_V2.md), прав — [THIRD_PARTY_NOTICES](../THIRD_PARTY_NOTICES.md).

## Приоритеты продолжения

1. **P0, до масштабирования:** независимое научное ревью первой связки; начинающий студент решает перенос B и объясняет результат. Согласовать рубрики и оценить реальную нагрузку. Наличие кода и этого отчёта не закрывает приёмку обучения.
2. **P0, до конкретных следующих уроков:** проверить источник опубликованного маршрута аторвастатина, данные среды/спектров и условия assays. Недостающие измерения не заменять условными числами без маркировки.
3. **P1:** написать M01-L02 и M02, связать их с существующим введением и общим досье; затем последовательно готовить остальные уроки по реестру. Старые главы в архиве служат материалом, но не готовой новой редакцией.
4. **P1:** интегрировать HPLC-прототип в полноценную пару M10, провести предметную проверку переноса средних пиков/ограничений и пилот интерфейса. Спектрофотометрический тренажёр и графический редактор карты пока не реализованы в новой структуре.
5. **P1:** завершить проверяемые Vina/PySCF-маршруты и границы задач; не менять химические эталоны ради теста.
6. **P2:** проверить пакет в тестовом курсе Stepik, перенос ссылок/медиа и действительный grader; провести итоговую защиту досье. До этого не объявлять локальную сборку выпуском курса.
