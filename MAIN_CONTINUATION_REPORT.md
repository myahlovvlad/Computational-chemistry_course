## Предметные рецензии вместо общего пересказа

В M06, M07 и M11 методические сопоставления связаны с GFN2-xTB, PySCF и Vina. В заданиях различаются опубликованный benchmark, версия программы, сходимость собственного расчёта и независимая проверка целевой системы. Старые локальные экспериментальные статьи сохранены как отдельные сравнения типов свидетельства. Внешние методические тексты не объявляются прочитанными или включёнными в пакет; без чтения полной работы полная мини-рецензия NOT_RUN.

В M12 основной разбор привязан к MoleculeNet, DOI 10.1039/C7SC02664A. Три выбранные фактические строки Table 3 получены из первичного NCBI BioC; повторное извлечение сверило значения и SHA исходного ответа. Notebook вычисляет направление улучшения, разности RMSE/AUC и ограниченное относительное уменьшение ошибки. Рубрика требует объяснить различие endpoint/единиц/split, ограниченность сравнения лучших моделей и невозможность перенести чужую метрику на A2A/HMGCR. Доверительные интервалы не выдумываются. Полный текст с лицензией CC BY-NC не перераспространяется: локально доступен явно ограниченный набор фактов и ссылка на первичный текст.

## Сохранение версий данных

Архив удалённых веток частично использует ссылки на канонические файлы. Для дальнейшей редакции добавлен `scripts/preserve_branch_dataset_versions.py`: старые байты извлекаются по исходному Git blob, проверяются одновременно по blob ID и SHA256 и сохраняются в неизменяемом объекте. Меняется только путь хранения; branch/commit/source path и эталонные хеши не подменяются. В этом изменении отдельно сохранена одна прежняя версия. Проверка подтвердила все **47 896 соответствий / 15 406 уникальных файлов**.
