# Тренажёры и проекты

[Хроматографический прототип](trainers/hplc/index.html) работает локально: откройте файл браузером или запустите `python -m http.server --directory web-training`. Он связан с линией B и M10. Вопрос, прогноз и следующий опыт экспортируются в JSON для разделов 6/9 досье. Тренажёр не оценивает качество ответа автоматически.

В основе — 20 экспериментальных строк из Table 1 Crevar-Sakač et al. (2013), DOI [10.3390/molecules18032469](https://doi.org/10.3390/molecules18032469), CC BY 3.0. Наша полная квадратичная регрессия предсказывает только удерживание первого/последнего аналита в диапазонах ACN 60–70%, T 30–40 °C, F 0,8–1,2 мл/мин при фиксированных условиях статьи. Точки между опытами — прогноз, не новые измерения. Ошибка подгонки не является независимой оценкой точности.

Сигналы Gaussian, их ширины/высоты и перенос двух средних положений — явно условные учебные допущения. У исходной таблицы нет необходимых сырых сигналов и ширин у основания для экспериментального Rs. При изменении pH, колонки или режима элюирования страница прекращает предсказывать: требуется новый эксперимент. Это осмысленный результат исследования, а не ошибка интерфейса.

Модель пересобирается `python scripts/build_hplc_trainer.py` в профиле `chem`. Публикуются `model.json`, исходный CSV, метод и SHA256. Преподаватель сопоставляет решение студента с источником и назначением процедуры; ICH Q14/Q2(R2) не сводятся к одному Rs.

Спектрофотометрический тренажёр и редактор карты пока **NOT_RUN / не реализованы в новой структуре**. Файловая карта `concept_map.json` и накопительное досье уже доступны в самостоятельных уроках. Наличие этих записей не удостоверяет понимание студента.

`projects/screening/app.py` — перенесённый проект Streamlit для IDE. Его вычислительное ядро проверяется отдельно; старый интерфейс не объявляется готовым тренажёром A/B и требует предметной переработки.
