# Подготовка к Stepik

Действующая программа main содержит 28 уроков, 56 Notebook и 212 текстовых шагов, включая переходы и задания по статьям. Сборка `parser/dist/stepik-api-20261120-v2` проверена локально (`practicuum/evidence/20261120-stepik-api-package-v2/check.json`); 25 stdlib-проверок относятся к ограниченным численным полям. Текущая редакция всех 28 разборов с углублёнными объяснениями проверена полным прогоном 56 Notebook (`practicuum/evidence/20261120-reasoning-full/notebook-summary.json`); прежние проверки сохранены как исторические свидетельства. Это **не профессиональный релиз** и не публикация.

Сборщик включает shared/data и закреплённую среду; исключает преподавательские решения, личный workspace и NIST raw cache. Notebook исполняются в локальном Jupyter/WSL, а не предполагаемом RDKit grader Stepik. Права/атрибуция сохраняются.

Подготовлены [пошаговый API-маршрут](../maintenance/STEPIK_API_GUIDE.md), offline-планировщик и create-only отправщик с журналом ID и GET-сверкой. Проверены шесть локальных сценариев API-клиента, полный план на реальном пакете и переносимый M11-L02. План полного импорта содержит 14 sections, 28 lessons, 28 units и 240 текстовых шагов: 212 исходных плюс 28 шагов скачивания. Реальные URL архива/ресурсов ещё требуется назначить и проверить. OAuth и создание объектов Stepik **NOT_RUN**; probe GET остановлен проверкой TLS-сертификата. Никаких реальных объектов через подготовленные инструменты не создано.

После дальнейших изменений M07/M08 потребуется следующая неизменяемая сборка. **NOT_RUN:** загрузка assets/доступность ссылок, API-объекты тестового курса, отображение формул, полный round-trip решений и реальный Stepik grader. Для доказательства платформенной пригодности локального запуска недостаточно.

Выпуск **BLOCKED** научными критериями и отсутствием проверки платформы. Репозиторий консолидирован в `main` по поручению автора; публикация в действующий Stepik-курс не выполняется.

Дополнительная сборка `parser/dist/professional-quantum-io-20261119` включает lossless scratch/guard controls и самостоятельный electronic checkpoint analyzer. Её локальная целостность проверяется отдельно от состояния ожидающих расчётов; метод хранения не меняет научные критерии выпуска.
