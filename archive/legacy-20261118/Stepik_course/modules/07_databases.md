# Модуль 7. Химические данные: от скачанной таблицы к сопоставимым измерениям

**Автор / аффилиация:** заполняются автором курса. **Время:** 5 часов. **Задача:** собрать выборку, в которой смысл значений сохранён.

**Аннотация.** Большая база содержит разные типы измерений и контексты. Мы различаем идентификатор структуры, активность и ассей, изучаем API и работаем с локальным снимком. Единицы и знаки отношений проходят явную проверку. Итог — кураторская таблица с обоснованными исключениями.

**План:** источники → получение → единицы → кураторство. **Путь:** от «скачать всё» к «сохранить сопоставимость». **Результаты:** выбрать источник; перевести концентрацию в pIC50; распознать несопоставимые строки.

## 7.1. Структура не равна измерению

В таблице «Химеры» у одной молекулы два значения: 100 и 0,1. Это может быть идеальное согласие — если первое в нМ, а второе в мкМ. Прежде чем усреднять, восстановите единицы.

PubChem полезен для структур, идентификаторов и связанных сведений; ChEMBL связывает соединения, мишени, ассеи и измерения активности. **REST API — Representational State Transfer Application Programming Interface** — позволяет получать структурированные ответы. JSON — JavaScript Object Notation — формат данных, а не гарантия их качества.

## 7.2. Воспроизводимое получение

Рабочий протокол: записать URL/параметры и время получения; сохранить сырой ответ; обработать пагинацию и ошибки; создать локальную таблицу; указать лицензию и идентификаторы записей. Сетевой сбой не должен выглядеть как отсутствие активности.

| Источник для практики | Плюс | Ограничение |
|---|---|---|
| Живой API | Актуальный ответ | Зависимость от сервиса и изменений |
| Снимок данных | Повторяемость учебного задания | Нужна дата и паспорт |
| Искусственные записи | Можно точно задать ловушки | Нельзя выдавать за измерения |

Основная проверка курса использует `activities.csv`. Работа с живым API — самостоятельное расширение; коммерческие структуры для него не нужны.

## 7.3. Логарифм с единицами

Для положительного IC50, выраженного в моль/л, `pIC50 = −log10(IC50)`. Значения 100 нМ и 0,1 мкМ дают 7. `IC50 > 10 мкМ` означает `pIC50 < 5`, а не точное значение 5. Нулевые, отрицательные и отсутствующие концентрации в этот логарифм не подставляют.

```python
from chemistry import p_activity
print(p_activity(100.0, "nM"))  # 7.0
```

**Быстрый результат:** исправить ложное тысячекратное расхождение двух строк в тренажёре единиц.

## 7.4. Что нельзя объединять

IC50 зависит от модели и условий теста; Ki и Kd описывают другие величины. Значения из клеточного и ферментативного ассая не становятся сопоставимыми после перевода единиц. В учебной политике оставляем один endpoint, конкретные `target_id` и `assay_id`, знак `=`, положительное число и известные единицы. Это консервативное упрощение для задания; в исследовании сопоставимость требует чтения протоколов.

Кейс B: отобрать строки из искусственного снимка. Скелет пропускает проверку endpoint, единиц и отношения. Три проверки: 100 нМ → 7; `>` не превращается в точное наблюдение; клеточный тест другой мишени не попадает в нужную группу. Интерфейс показывает причины исключений и число строк по каждому правилу.

**Контроль.** «pIC50=7 — это 100 мкМ?» **Ответ:** 100 нМ. «Ki можно безусловно смешать с IC50?» **Ответ:** нет. «Пустой ответ сервера — неактивное вещество?» **Ответ:** нет.
