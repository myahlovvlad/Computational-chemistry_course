# Модуль 14: Передаваемый лабораторный конвейер

## Сущность и назначение

Проверить работу с чужим CSV, сохранность строк и один вычислительный контракт для CLI и интерфейса.

## Данные и workflow

molecules.csv; дополнительный ошибочный CSV без нужного столбца.

CSV contract → ядро → журнал всех строк → паспорт → CLI → проверка передачи.

[Паспорт данных](../datasets/README.md); [установка](../SETUP.md).

## Два этапа работы

1. [Разбор кейсов и кода](../notebooks/lab14.ipynb): пояснение → короткая ячейка → интерпретация.
2. [Самостоятельные кейсы](../notebooks/lab14_practice.ipynb): три условия, входы, места для собственного решения, проверки и рубрика.

CLI и прямой вызов сохраняют 12 строк и hash; отсутствующий столбец/повторный ID отклоняются; Streamlit — тот же pipeline.

Исторический benchmark относится к прежней редакции. Свежие результаты парного формата публикуются отдельно в paired-execution.json. Пустые задания имеют NOT_RUN, даже если notebook запускается без ошибок.

[Ключ преподавателя](../solutions/lab14.md). Приложения создаются и отлаживаются в [IDE](../ide/README.md).
