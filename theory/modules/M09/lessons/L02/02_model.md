# Модель: проверка прогноза и ранг наблюдений

H=X(XᵀX)⁻¹Xᵀ, hᵢ=Hᵢᵢ. Для линейного МНК остаток исключённого наблюдения eᵢ/(1−hᵢ) проверяем явным переобучением. Исключаем целую концентрацию. Если появятся повторные временные ряды одного приготовления, они должны оставаться в одной группе.

Для новой строки q=(1,x) дисперсия среднего s²q(XᵀX)⁻¹qᵀ, дисперсия нового наблюдения добавляет s². Это условные интервалы для той же модели ошибок. Отрицательная нижняя граница скорости диагностирует ограничение линейного предположения; молчаливое обрезание не исправляет модель. Проверку по пяти условиям нельзя назвать независимой экспериментальной валидацией.

Одно λ=k_open+k_close допускает непрерывное семейство k_open=fλ, k_close=(1−f)λ. Для u=k_open/λ₀, v=k_close/λ₀ наблюдение z₁=u+v имеет якобиан [1,1] ранга 1. Добавление равновесной доли z₂=u/(u+v) даёт вторую строку [v/(u+v)²,−u/(u+v)²]; при u,v>0 ранг становится 2. Это структурная диагностика, не оценка практической точности. Полные совместные временные ряды с калибровками могут содержать больше информации, чем один λ.

Для B два опубликованных apparent k при pH 4.5 задают альтернативные масштабы времени. Точки 0,0.25,0.5,1,2,4·ln(2)/k — предложенный план, не измерения. Их осуществимость зависит от стабильности проб и возможных побочных процессов.
