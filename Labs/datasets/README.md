# Паспорта datasets

## Искусственные данные курса

`molecules.csv` содержит 12 записей простых структур. Названия — учебные подписи. M01/M02 — одинаковый граф этанола; M03/M04 — соль и кислота, объединяемые только выбранной parent-политикой; M05 — ковалентный Cl; M06 — катехол; M08/M09 — намеренные ошибки; M10/M11 — стереопара. Реальные измеренные активности этим структурам не приписываются.

`activities.csv` содержит восемь **вымышленных** наблюдений. T1/T2 и A1/A2 — условные IDs. Результат кураторства: R01/R02 дают pIC50=7; остальные записи не удовлетворяют явно заданной политике точного IC50 для T1/A1. Это материал для проверки единиц и происхождения, не выборка для обучения биологической активности.

`factorial.csv` — искусственный план 2×2, y в условных единицах. Уровни A/B кодированы ±1. Ошибка измерения не задана; статистическую значимость по четырём точкам насыщенной модели оценить нельзя.

`routes.csv` — два вымышленных линейных маршрута. Выходы в долях. `assumed_cost` — условная сумма для одинаковой теоретической загрузки, не цена поставщика. Упрощённая нормировка не учитывает стадии очистки и масштаб.

## ESOL / Delaney

`esol.csv` — открытый корпус из [DeepChem datasets](https://raw.githubusercontent.com/deepchem/deepchem/master/datasets/delaney-processed.csv), 1128 строк. Первичный источник: Delaney, *ESOL: Estimating Aqueous Solubility Directly from Molecular Structure*, J. Chem. Inf. Comput. Sci. (2004), [DOI 10.1021/ci034243x](https://doi.org/10.1021/ci034243x).

Цель: `measured log solubility in mols per litre`, логарифм молярной растворимости. В файле есть `ESOL predicted ...` и готовые признаки: они **не используются** как входы нашей модели. Пять признаков вычисляются заново из SMILES. Состояние образца и условия не полностью представлены; корпус удобен для обучения методологии, не для универсального сервиса растворимости.

Исходные строки не изменены. SHA256: `8c06a76f0c6487d29ab0f903e6a7a7139f189ab3c1178f159c8be8964602f189`. Лицензия программного проекта-источника сохранена в `DEEP_CHEM_LICENSE.txt`; библиографическое происхождение измерений приведено отдельно и не подменяется лицензией кода. Для нового коммерческого применения требуется собственная проверка условий источников.

## Докинг 1IEP

Каталог `docking/` содержит подготовленные рецептор, лиганд PDBQT/SDF, box и официальный выход из примера AutoDock Vina. Источник и точный upstream commit каждого файла — в `docking/provenance.json`; лицензия проекта — `docking/UPSTREAM_LICENSE.txt`. Вход не подготовлен автором курса из сырого PDB: это **готовый официальный tutorial**. В ЛР 10 студент сначала понимает подготовку, потом повторяет расчёт.

Для Vina нужна отдельная исполняемая программа в PATH; бинарник не хранится в Git. В новой парной редакции полный разбор модуля 10 требует реального запуска, иначе BLOCKED. В старом helper доступен ограниченный `official-reference-analysis`; это не исполнение Vina. Подготовка из raw PDB и symmetry-corrected RMSD остаются отдельными доказательствами.

## Электронный расчёт

Для ЛР 12 экспериментальный dataset не требуется. Геометрия H2 задаётся в Å, расчёт переходит в bohr. STO-3G коэффициенты водородных 1s-функций приведены в коде; описание базиса доступно в [Basis Set Exchange](https://www.basissetexchange.org/). Реализация ограничена RHF/H2; DFT-результаты в dataset не вымышлены и не подставлены.

Hash всех файлов и единицы находятся в `manifest.json`. Даты и версии фактических запусков — в benchmark; они не являются датами исходных измерений.

## Самостоятельные кейсы парной редакции

`practice_cases.json` — авторские входы 42 учебных кейсов (17.11.2026), сгруппированные по 14 модулям. Числа DoE, концентраций, цен и toy-прогнозов вымышлены; не использовать как экспериментальную базу. Ссылки на ESOL/1IEP используют исходные реальные snapshots и их собственные паспорта/лицензии. Геометрии и результаты расчётов не выдаются за измерения. В `Labs/practice-case-registry.json` находятся условия и критерии; ответы отделены от ученических notebooks.
