
Программа курса адаптирована под полностью локальный open-source стек (без зарубежных лицензий, без выноса данных во внешние облака и без прав администратора). Это идеальный фреймворк как для самостоятельного прохождения (роль автора как первого студента), так и для последующей передачи в университеты, НИИ и корпоративный сектор РФ (B2B EdTech).
Фокус курса смещен с заучивания кода на System Design (понимание архитектуры процессов и ограничений алгоритмов). Рутинное написание кода делегируется связке локального окружения и ИИ-ассистента (DeepSeek).

🚀 Программа курса: «Цифровая химия: Локальный open-source стек и ИИ»

Модуль 1. Парадигма In Silico и системный дизайн R&D

• Теория: Роль хемоинформатики в современном материаловедении и разработке лекарств (Drug Discovery). Анатомия вычислительного эксперимента. Почему симуляция — это тоже эксперимент? Понятие воспроизводимости данных. Обзор карты доступного open-source софта в РФ.
• Практика: Построение архитектурной карты (System Design) конвейера проекта: от постановки задачи до финального отбора кандидатов.

Модуль 2. Локальное окружение и ИИ как старший лаборант

• Теория: Философия «Инструмент ради задачи». Базовые принципы работы с терминалом. Горячие клавиши (Ctrl+Shift+C/V), автодополнение через Tab. Что такое PATH и почему программы теряются. Виртуальное окружение как изолированная «колба». Быстрый менеджер uv против классического pip. Настройка системных промптов для DeepSeek.
• Практика: Развертывание локального окружения на Python 3.11, установка библиотеки RDKit, настройка ИИ-ассистента для отладки химического кода.

Модуль 3. Компьютерный язык химии: Графы и строки

• Теория: Как компьютер видит молекулу. Введение в теорию графов (узлы и связи). Линейные форматы кодирования структур: синтаксис SMILES и InChI. Проблема изомеров и таутомеров. Зачем нужна канонизация. «Тихие ошибки» грязных исторических баз данных.
• Практика: Разработка скрипта для автоматической очистки базы данных: удаление солевых мостиков, детекция некорректных валентностей, приведение к каноническому SMILES.

Модуль 4. Оцифровка свойств: Химические дескрипторы

• Теория: Перевод структуры в вектор признаков. Физико-химические дескрипторы (LogP, молекулярный вес, площадь полярной поверхности PSA). Правило пяти Липинского (Rule of 5) и его современные модификации. Молекулярные фингерпринты (Morgan/ECFP) как цифровые отпечатки пальцев молекул. Метрика сходства Танимото.
• Практика: Расчет профиля биодоступности для библиотеки соединений, поиск химических «близнецов» по индексу Танимото.

Модуль 5. Химический веб-парсинг и API

• Теория: Устройство глобальных баз химических данных (PubChem, ChEMBL). Что такое REST API и как общаться с серверами баз данных программно. Структура JSON-ответов. Логика построения локальных зеркал данных и кэширования для защиты от нестабильного интернета.
• Практика: Написание автоматического ИИ-парсера, который по названию биологической мишени выкачивает структуры всех протестированных веществ и их параметры активности (IC₅₀ / EC₅₀).

Модуль 6. Локальная визуализация данных

• Теория: Психология восприятия данных стейкхолдерами. Переход от таблиц к интерактивным картам химического пространства. 2D-генерация координатных сеток для молекул. Основы 3D-графики молекулярных конформаций в браузере.
• Практика: Создание интерактивной HTML-таблицы с возможностью фильтрации, поиска и вращения 3D-структур молекул прямо внутри ячейки ноутбука.

Модуль 7. Фильтрация химического брака: Воронка скрининга

• Теория: Понятие «Drug-like» и «Lead-like» подмножеств. Почему высокая активность в тесте бывает фальшивой. Молекулы-интерференты (PAINS), ломающие оптические и ферментативные тесты. Фильтры реакционной способности (алкилирующие агенты, токсичные группы). Архитектура многостадийной воронки отбора.
• Практика: Создание жесткого фильтра очистки коммерческих каталогов реактивов для отсечения «химического мусора» перед закупкой.

Модуль 8. Прогнозирование свойств: Машинное обучение (QSAR/QSPR)

• Теория: Постулат «Структура определяет свойство». Математическая логика классических алгоритмов машинного обучения (Random Forest, XGBoost) применительно к дескрипторам. Понятие области применимости модели (Applicability Domain) — почему нельзя предсказывать свойства веществ, кардинально отличающихся от обучающей выборки. Метрики валидации (R², RMSE, ROC-AUC).
• Практика: Обучение локальной ML-модели для предсказания растворимости (датасет ESOL) или токсичности (LD50) новых соединений с жестким контролем границ применимости.

Модуль 9. Молекулярный докинг: Геометрия взаимодействия

• Теория: Концепция взаимодействия «Замок-Ключ». Биологические мишени: структура белков, базы данных PDB. Революция AlphaFold/ESMFold. Анатомия скоринговых функций докинга: оценка энергии Ван-дер-Ваальса, электростатики и водородных связей. Ограничения жесткого докинга (почему высокий скоринг не гарантирует работу in vivo).
• Практика: Локальный запуск open-source пакета AutoDock Vina, проведение докинга тест-лиганда в полость белка и анализ геометрических контактов.

Модуль 10. Квантово-химические расчеты (DFT) для практиков

• Теория: Поверхность потенциальной энергии (ППЭ). Локальные минимумы (реальные молекулы) и седловые точки (переходные состояния реакций). Вычислительный компромисс: методы DFT (теория функционала плотности) против полуэмпирики. Как выбрать базисный набор и функционал без углубления в высшую математику. Интерпретация выходных файлов.
• Практика: Использование локального open-source пакета PySCF/ASE для расчета термодинамики и энергии активации реакции изомеризации.

Модуль 11. Компьютерный ретросинтез

• Теория: Логика ретросинтетического анализа по Илайасу Кори. Как компьютер разбирает целевую молекулу с конца. Сравнение подходов на основе жестких правил (Rule-based) и нейросетевых моделей (AI-driven). Проблема доступности сырья: интеграция с прайс-листами поставщиков реактивов.
• Практика: Построение дерева синтеза для предсказанного ML-кандидата с подбором коммерчески доступных стартовых реагентов.

Модуль 12. Промышленная автоматизация и Streamlit

• Теория: Превращение кода в отчуждаемый продукт. Зачем упаковывать скрипты в CLI (интерфейс командной строки) через argparse. Архитектура быстрых реактивных веб-приложений на Streamlit. Принципы передачи инструментов коллегам безболезненно для их окружения.
• Практика: Сборка полноценного локального веб-приложения, которое объединяет модули очистки, фильтрации PAINS и предсказания свойств (QSAR) в единый графический интерфейс с кнопкой «Скачать Excel-отчет».
