# Что хранится в evidence

Это журнал доказательств курса: фактические запуски, первичные источники, протоколы, версии программ, входные SHA-256, результаты, отрицательные проверки и ограничения. Он нужен для воспроизведения и проверки выводов. Название папки или наличие `result.json` сами по себе не означают научный PASS.

Текущий маршрут начинается с [реестра курса](../../docs/status/course-status.json). Объём, потребители и правила хранения описаны в [разборе evidence](../../docs/maintenance/EVIDENCE_RETENTION.md), машинный список — [EVIDENCE_INVENTORY.json](../../docs/maintenance/EVIDENCE_INVENTORY.json).

- Источники, протоколы и первичные научные результаты сохраняются.
- Исторические данные из `archive/branch-datasets/manifest.json` защищены исходными хешами.
- Активные checkpoint, restart и данные незавершённых запусков нельзя удалять как кэш.
- Повторные исполненные Notebook и копии входов — кандидаты для проверяемого архивирования или устранения дублирования с обновлением потребителей. Отсутствие буквальной ссылки не доказывает ненужность файла.
- Python bytecode можно восстановить автоматически. На момент проверки такого кэша здесь не было.

Безопасный повторный аудит ничего не удаляет:

```text
python scripts/audit_evidence.py --out docs/maintenance/EVIDENCE_INVENTORY.json
```
