# Решение: какие данные собирать дальше

Ошибка leave-one-concentration-out у кофеина около 0.00827 min⁻¹ оценивает перенос между пятью условиями. Она не измеряет погрешность новой серии при другой температуре. По Table 4 нельзя заново fit Eₐ: температура только одна.

Для B подготовьте независимые серии из обеих форм, калибровки каждого отклика, blank, quench и контроль автосэмплера. Совместная модель должна учитывать плато, baseline, пропуски и ошибки измерений. Проверяйте баланс и остатки; сравнивайте с моделью побочного распада. Неопределённость оценивайте профильным правдоподобием или bootstrap независимых приготовлений. Новый fit без сырых наблюдений остаётся NOT_RUN.

Сохраните в досье область применимости, матрицу наблюдаемости, план отбора проб и критерии пересмотра. В M10 требуется проверить разделение кислоты, лактона и иных продуктов; один суммарный UV-сигнал не обеспечивает их независимое измерение.
