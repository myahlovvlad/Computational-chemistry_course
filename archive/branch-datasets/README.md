# Данные удалённых веток

`manifest.json` связывает исходную ветку, commit и путь с сохранённым файлом и SHA256. Одинаковые Git blobs используют одну копию: в действующих данных или историческом архиве. Недостающие версии находятся в `objects/`; их назначение определяется исходным путём в манифесте.

Сохранены все отслеживаемые файлы каталогов данных, evidence и результатов на вершинах веток, а также файлы научных форматов вне этих каталогов. Архив не подключён к учебной сборке и не является второй программой курса. Происхождение и лицензии наследуются из исходных паспортов; сохранение не означает научной валидации.

Полная история, включая промежуточные версии, дополнительно сохранена вне репозитория в `Computational-chemistry-backup-20261119/all-branches.bundle`. Игнорируемые локальные расчёты и библиотеки не удалены. Проверка: `python scripts/verify_branch_datasets.py`.
