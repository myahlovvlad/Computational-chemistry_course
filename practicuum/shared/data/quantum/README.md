# Собственные расчётные опорные результаты

Кофеин, истрадефиллин и аторвастатин действительно рассчитаны PySCF 2.15.1 в изолированной среде WSL. Для каждого сохранены геометрия, полный `pyscf.log` и `result.json` с версиями, энергией и шестью вертикальными синглетными переходами. [Команда, исходный скрипт/вход и SHA256](../../../evidence/20261118-pyscf-reference/execution.json).

Протокол: ETKDGv3, seed 20261118, оптимизация MMFF; затем B3LYP/STO-3G с density fitting, сетка level 1, газовая фаза, SCF 1e-8, TDDFT 1e-6, шесть состояний, длиновая форма осцилляторной силы, два потока/лимит 3000 MB. Проверены завершение геометрической оптимизации, SCF и всех запрошенных TDDFT-состояний. Геометрия не оптимизирована DFT и не объявлена его стационарной точкой.

Это учебный собственный расчёт в минимальном базисе: нет растворителя, колебательной/тепловой структуры, абсолютного измеренного коэффициента поглощения и экспериментальной валидации спектра. Числа не являются воспроизведением опубликованного водного протокола ксантинов. Полные энергии разных по составу молекул нельзя ранжировать как устойчивость, эффективность или качество доставки.

Наличие этих файлов не завершает разработку уроков M07/M08. Они служат проверяемым входом для будущего анализа; независимое научное ревью, сравнение с подходящим экспериментом и перенос навыка остаются NOT_RUN. При повторении используйте новый каталог `--out`, не подменяйте прежние результаты.
