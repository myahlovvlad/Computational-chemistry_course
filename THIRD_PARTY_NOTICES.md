# Сторонние материалы и происхождение

Исходный код и учебные тексты курса отделены от справочной библиотеки. Само размещение репозитория не предоставляет права на сторонние книги. Их PDF, Markdown-конвертации и изображения исключены из Git.

- Подготовленные данные примера AutoDock Vina сохранены с источниками/commit в `Labs/datasets/docking/provenance.json`; лицензия upstream — `UPSTREAM_LICENSE.txt` рядом с ними. Исполняемый бинарник загружается отдельно и в репозитории отсутствует.
- ESOL взят из DeepChem datasets и сопровождается ссылкой на работу Delaney. Лицензия проекта DeepChem сохранена в `Labs/datasets/DEEP_CHEM_LICENSE.txt`. Лицензия программного проекта не объявляется автоматически универсальной лицензией всех исходных экспериментальных публикаций.
- PyMuPDF/PyMuPDF4LLM и найденный навык pdf-to-markdown имеют собственные условия использования; их код не включён в репозиторий. Для повторной конвертации нужно установить их самостоятельно по официальным инструкциям.
- Параметры STO-3G для водорода в учебной RHF-реализации — стандартные числовые данные базисного набора; справочный источник — Basis Set Exchange. Код интегралов и SCF написан как ограниченный учебный пример, не скопирован из квантового пакета.
- Искусственные CSV, графики notebook и пояснения созданы для курса. У них нет вымышленного экспериментального происхождения.

Правообладатель курса выбирает условия дальнейшего распространения собственных материалов отдельно; лицензии сторонних проектов этим документом не изменяются.
