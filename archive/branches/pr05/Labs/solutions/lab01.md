## M01-C1. Вернуть пропущенный фактор

Нулевой остаток насыщенной модели не является оценкой ошибки.


```python
case_input = {'A': [-1, 1, -1, 1], 'B': [-1, -1, 1, 1], 'y': [43, 47, 37, 73]}
x=np.column_stack([np.ones(4),case_input['A'],case_input['B'],np.multiply(case_input['A'],case_input['B'])]); b=np.linalg.solve(x,case_input['y']); answer={'beta':b.tolist(),'effects':(2*b[1:]).tolist(),'residual_df':4-np.linalg.matrix_rank(x)}
```


Ожидаемый численный контракт: `{"beta": [50, 10, 5, 8], "effects": [20, 10, 16], "residual_df": 0}`.


## M01-C2. Повторы меняют доказательство

Нужны независимые повторные измерения при фиксированных условиях; копии строк не являются повторами.


```python
case_input = {'A': [-1, -1, 1, 1, -1, -1, 1, 1], 'B': [-1, -1, -1, -1, 1, 1, 1, 1], 'y': [43, 45, 47, 49, 37, 39, 73, 75]}
x=np.column_stack([np.ones(8),case_input['A'],case_input['B'],np.multiply(case_input['A'],case_input['B'])]); y=np.array(case_input['y']); b=np.linalg.lstsq(x,y,rcond=None)[0]; answer={'beta':b.tolist(),'pure_error_df':8-np.linalg.matrix_rank(x),'pure_error_ms':float(np.sum((y-x@b)**2)/4)}
```


Ожидаемый численный контракт: `{"beta": [51, 10, 5, 8], "pure_error_df": 4, "pure_error_ms": 2}`.
