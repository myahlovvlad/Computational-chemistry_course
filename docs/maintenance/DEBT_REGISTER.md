В каждом новом исследовании преподаватель проверяет: происхождение данных → выбор модели и допусков → воспроизведение → неопределённость → отрицательные результаты → границы переноса A/B → следующий проверяющий эксперимент. Студенческий ответ содержит доказательства, а не только итоговое число.
