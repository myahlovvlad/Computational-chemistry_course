# Ориентир преподавателя, M03-L01

`reference.py` исполняет только вычислительную часть. Для записи аторвастатина ожидаются два заданных тетраэдрических центра; их индексы зависят от конкретного графа. Удаление стереохимии сохраняет формулу/массу и теряет конфигурационные сведения. Число центров и правильная строка не заменяют объяснение.

Критерии: исходная строка и источник сохранены; формула/масса рассчитаны для явно выбранного представления; сравнение демонстрирует потерю информации; ученик различает идентичность цифрового графа и идентичность физического образца; предлагает независимую проверку оставшегося вопроса. Например, обычная ахиральная масса сама по себе не доказывает энантиомерную чистоту; выбор хирального анализа требует обоснования применимости и стандартов.

Для поиска по связности упрощение может быть целесообразно, если оригинал сохранён и политика названа. Для переноса исходной конфигурации в модель оно недостаточно. Не требовать безусловного запрета любой нормализации.

Ответ оценивает преподаватель по шкале 0–3 из M01. Автопрогон пустого шаблона, исполнение reference.py и научное понимание — три разных события. Независимое научное ревью и пилот на начинающих пока NOT_RUN.
