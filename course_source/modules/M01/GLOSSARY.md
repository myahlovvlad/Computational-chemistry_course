# Словарь M01: сокращения, обозначения и смысл

Словарь сопровождает [разбор](01_guided_case.ipynb) и [лабораторную](02_independent_lab.ipynb). При первом чтении достаточно находить встретившийся термин; заучивать таблицу перед исследованием не требуется. Формулы и условия собраны в [математическом протоколе](MATHEMATICAL_PROTOCOL.md).

## Величины и математические обозначения

| Запись | Расшифровка / определение | Как понимать в этой работе |
|---|---|---|
| S | Solubility — растворимость | В этом CSV — молярная концентрация насыщенного водного раствора; условия не детализированы |
| mol/L, mol·L⁻¹ | Моль на литр | Единица молярной концентрации |
| logS, y | log10(S/(1 mol·L⁻¹)) | Десятичная логарифмическая запись; отрицательная logS не означает отрицательную концентрацию |
| ŷ, predicted | Прогноз | Уже вычисленное архивное значение, не новое измерение |
| measured | Измеренное значение | Архивное наблюдение; его индивидуальная неопределённость в CSV не указана |
| e, residual | Остаток ŷ − y | Положительный — прогноз выше наблюдения; сам по себе не определяет причину расхождения |
| MAE | Mean Absolute Error — средняя абсолютная ошибка | Среднее модулей остатков; не верхняя граница для каждой записи |
| RMSE | Root Mean Squared Error — корень средней квадратической ошибки | Усиливает вклад крупных отклонений; в этой задаче RMSE ≥ MAE |
| F | 10^\|e\|, кратность расхождения | Во сколько раз больше одно из соответствующих значений S; не вероятность |
| τ, tau | Допуск по модулю остатка | В упражнении τ = 1 соответствует кратности 10; это учебный ориентир |
| Cτ | Доля записей с \|e\| ≤ τ | Описательная доля в выбранном архиве; не вероятность будущего успеха |
| x, φ(x), θ | Представление объекта, признаки, параметры модели | Разные уровни вычислительного отображения структуры в свойство |
| pH | Отрицательный десятичный логарифм активности ионов водорода | Характеристика кислотности среды; значение для записей архива не предоставлено |
| T | Температура | Физическое условие измерения, отсутствующее в нашем CSV |
| logP | Логарифм коэффициента распределения нейтральной формы между фазами | Свойство распределения, отличается от водной растворимости; конкретные фазы и условия нужно указывать |

## Предметная область и источники

| Сокращение / термин | Полная форма | Роль и ограничение |
|---|---|---|
| ESOL | Estimated SOLubility — оценённая растворимость | Название модели Delaney; не название независимого эксперимента, выполненного студентом |
| QSPR | Quantitative Structure–Property Relationship | Количественная связь «структура — свойство» |
| QSAR | Quantitative Structure–Activity Relationship | Количественная связь «структура — активность»; иной endpoint, чем растворимость |
| SMILES | Simplified Molecular Input Line Entry System | Строковое представление молекулярной структуры; не полный паспорт образца |
| IUPAC | International Union of Pure and Applied Chemistry | Международный союз теоретической и прикладной химии; источник терминологии |
| DOI | Digital Object Identifier | Постоянный идентификатор публикации; наличие DOI не доказывает выполненность нашего расчёта |
| ACS | American Chemical Society | Издатель оригинальной работы; права на её материалы не следуют автоматически из лицензии другого репозитория |
| PDB | Protein Data Bank | Банк экспериментальных трёхмерных структур; 1HWK — идентификатор конкретной записи |
| A2A | Adenosine A2A receptor | Аденозиновый рецептор подтипа A2A, линия A курса |
| HMG-CoA | 3-hydroxy-3-methylglutaryl-coenzyme A | 3-гидрокси-3-метилглутарил-коэнзим A |
| HMGCR | Символ гена HMG-CoA reductase | Ген, кодирующий HMG-CoA-редуктазу; в досье важно различать ген и белок-фермент |
| CNS / ЦНС | Central Nervous System | Центральная нервная система |
| BBB / ГЭБ | Blood–Brain Barrier | Гематоэнцефалический барьер; растворимость сама по себе не измеряет проницаемость через него |
| QM | Quantum Mechanics | Квантовая механика; один из подходов вычислительной химии, не используемый для нашего сравнения колонок |
| MM | Molecular Mechanics | Молекулярная механика; описание системой силового поля, иной уровень модели |
| Endpoint | Измеряемая конечная характеристика | Например, растворимость или клеточная концентрация; перенос вывода между ними требует основания |
| Экспозиция | Контакт системы с веществом, описанный релевантной концентрацией/временем | Нужны определение, условия и метод; структура комплекса не даёт клеточную экспозицию |

## Файлы, код и статусы

| Запись | Полная форма / значение | Что она доказывает |
|---|---|---|
| CSV | Comma-Separated Values | Табличный формат; сам не гарантирует единицы или корректность колонок |
| SMILES | Simplified Molecular Input Line Entry System | Строковая запись молекулярного графа; не полный протокол образца |
| JSON | JavaScript Object Notation | Формат структурированной записи, например исследовательского решения |
| SHA256 | Secure Hash Algorithm, 256-bit | Совпадение контрольной суммы подтверждает идентичность байтов; не химическую истинность |
| ID / row_id | Identifier / адрес строки | `row_id` зависит от порядка этого snapshot; не каноническая идентичность вещества |
| Snapshot | Зафиксированная версия данных | Даёт возможность повторить анализ тех же байтов |
| Raw | Неизменённые исходные данные | Сохраняются отдельно от производных преобразований |
| Workflow | Последовательность действий | Должна связывать научный вопрос, вычисление и решение |
| IDE | Integrated Development Environment | Интегрированная среда разработки; для будущих приложений и библиотек |
| CLI | Command-Line Interface | Интерфейс командной строки |
| RDKit | Название библиотеки хемоинформатики | Не требование M01; не нужно придумывать расшифровку имени |
| uv | Название менеджера Python-проектов | Создаёт изолированную среду; не математический метод |
| PASS | Проверка выполнена успешно в указанном объёме | Всегда читать scope: форматный PASS не оценивает научный вывод |
| FAIL | Проверка выполнена и не прошла | Нужны фактический результат и журнал |
| BLOCKED | Выполнение заблокировано конкретной причиной | Не равнозначно обнаруженной неправильности химического ответа |
| NOT_RUN | Проверка / решение не выполнены | Пустой шаблон и отсутствие студенческой работы не считаются успехом |
| insufficient_evidence | Недостаточно доказательств | Обоснованный содержательный вывод, если указано, каких данных не хватает |
