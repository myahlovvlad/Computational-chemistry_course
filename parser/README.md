# Подготовка локального пакета Stepik

Пошаговый маршрут с OAuth, планом запросов, пилотным уроком, состоянием импорта и проверкой — [экспорт через API](../docs/maintenance/STEPIK_API_GUIDE.md). `stepik_plan.py` не использует сеть. `stepik_send.py` по умолчанию показывает план; запись в Stepik включается только явным `--apply`. Живая проверка API и grader пока NOT_RUN.

Научные данные загружают и проверяют отдельные инструменты в `scripts/`; этот каталог собирает авторские учебные шаги. Вход — `programm/course.json`, отдельные MD теории/практики и пары Notebook. Каждый MD становится отдельным текстовым шагом; исходник и SHA сохраняются.

В профиле `base`:

```text
python parser/build.py --allow-partial --out parser/dist/review-v1
python parser/validate_package.py parser/dist/review-v1
```

Каталог вывода должен быть новым. Без `--allow-partial` сборка останавливается с BLOCKED, если какой-либо урок ещё не подготовлен. Частичный пакет явно перечисляет готовое и отсутствующее; он не называется полным курсом.

Результат: JSON текстовых блоков, исходные MD, Notebook и контрольные суммы. Код не включает преподавательские ответы, не делает сетевых запросов и не меняет действующий курс. Пакет предназначен для локального ревью. До публикации нужны реальные ID объектов Stepik, размещение файлов/медиа и преобразование локальных ссылок в доступные ученику URL. Полная воспроизводимая среда находится в репозитории, а не подразумевается встроенной в Stepik.

Официальная [документация Stepik API](https://github.com/StepicOrg/Stepik-API) описывает отдельные ресурсы и текстовые блоки. Локальная проверка структуры не удостоверяет фактическое отображение HTML/формул, доступ к Notebook или работу grader на платформе. Эти проверки **NOT_RUN**; вводить слово «пройдено» для них нельзя.
