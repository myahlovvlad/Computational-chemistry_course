# Интерпретация отрицательного результата

Фактический A2A результат: native-like sampling 9/9, top-1 recovery 0/9, средний top-1 RMSD≈9.559 Å. Исполнение PASS, научный критерий ранжирования FAIL. Нельзя скрывать его выбором одного seed или низкоранговой правильной позы.

Следующий протокол должен заранее определить сравнение гидратации, протонирования, receptor model и независимых кристаллических комплексов. Изменения после просмотра единственной native-позы проверяются на другом комплексе. Для HMGCR сначала устраняется структурный BLOCKED; A2A не заменяет его target-specific redocking.

В досье сохраните все поиски, химическую форму, frame, параметры, критерии, отрицательный результат и план пересмотра. В M12 статистическая модель активности будет иметь собственную проверку endpoint, групповой утечки, области применения и неопределённости; docking score нельзя использовать как экспериментальную метку без отдельного обоснования.
