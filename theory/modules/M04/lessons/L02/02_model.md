# Модель: apparent slope и комплексирование

При неизменной фазе и дополнительных термодинамических предпосылках ln x=a−ΔH/(RT). Для численного fit используем z=1000/T−mean(1000/T), ln x=β0+β1z. Тогда ΔH_app=−R·β1 kJ/mol, если R в J mol⁻¹ K⁻¹. Это условный наклон опубликованной мольной доли. Activities, состав смешанного растворителя, solvate equilibria и measurement errors могут менять интерпретацию.

OLS использует три остаточные степени свободы на пять температур; Student t интервалы и leave-one-temperature-out ошибки условны на модель ошибок. В таблице нет SD трёх исходных опытов. 100δ — относительное расхождение авторского x_calc с x, не measurement uncertainty; использовать его как вес означало бы подмену статистической модели.

Если S_mass в mg/mL означает g/L API equivalents, x — обычная мольная доля, то c_solvent=(S_mass/MW)(1−x)/x. Это algebraic diagnostic, не измеренная плотность. Большое изменение по T требует проверки определения x, dilution, единиц и фаз. Для смесей нужен явный подсчёт компонентов, а не произвольная effective molecular mass.

Для линейного 1:1 phase-solubility комплекса K=slope/[S0(1−slope)], CE=K·S0=slope/(1−slope). Обратная формула slope=K·S0/(1+K·S0). Кривизна A_N ограничивает безусловную линейную интерпретацию; A_L сама по себе не доказывает стехиометрию.
