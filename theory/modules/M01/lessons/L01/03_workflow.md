# Как пройдём первое исследование

Первый шаг — не выбрать библиотеку Python, а уточнить вопрос. В разборе A спросим: «Какие сведения об истрадефиллине у нас есть и чего они не доказывают?» Затем откроем две разные записи: карточку соединения и метаданные структуры комплекса A2A. Сопоставим их назначение и построим одно объяснённое ребро карты.

Словесный алгоритм: получить карточку → выписать её источник и тип сведений → назвать поддерживаемое утверждение → назвать остающееся неизвестным → выбрать подходящее следующее свидетельство → сохранить запись в досье. Здесь «карточка» реализуется словарём: у каждого поля есть имя и значение. Словарь не устанавливает истину; он не даёт потерять происхождение наблюдения.

Прежде чем увидеть пример интерпретации, сформулируйте собственный. Сравните его с разобранным и объясните различие. Затем лабораторная B потребует нового выбора на аторвастатине: аналогия помогает организовать проверку, но не переносит результат A на B.

Приёмка состоит из трёх частей. Техническая: вы смогли открыть записи и сохранить свой файл. Предметная: не перепутали структуру, расчёт и эксперимент. Исследовательская: предложили наблюдение, которое отвечает конкретному оставшемуся вопросу, и объяснили его ограничение. Пустой шаблон, выполнившийся без ошибки, закрывает только технический пункт.

Настройка среды описана в [руководстве](../../../../../scripts/README.md); для этого урока достаточно профиля `base`.
