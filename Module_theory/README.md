# Теоретический маршрут курса

Эта папка — **основная редакция теории**, а не список пустых заготовок. В каждой главе восемь последовательных разделов: входная задача, базовый метод, ограничения, углубление, разобранная практика и переход к собственной работе. Указания B01–B07 ведут к [карте источников](../Literature/READING_MAP.md).

Следуйте порядку: постановка → окружение → молекулярное представление → признаки → сходство → геометрия → данные измерений → скрининг → отчёт. После этого можно изучать докинг и QSPR; квантовая химия и ретросинтез расширяют методический инструментарий. Завершает маршрут передача конвейера. Предпосылки указаны в главах.

Полная навигация, включая связь каждой главы и notebook, — в [практикуме](../Labs/README.md) и `course-manifest.json`. Исходные заполненные черновики двух глав сохранены в `archive/source-drafts/`; они нужны для сравнения подачи и не являются действующими инструкциями.

Файлы названы по прежней схеме, чтобы сохранить внешние ссылки. Модуль 9 «Визуализация» добавлен для закрытия пропуска. Для чтения используйте таблицу в корневом README, а не алфавитную сортировку имён файлов.
