# Библиотека и конвертация PDF

Семь источников из локальной папки `Books` преобразованы установленным навыком [pdf-to-markdown](https://github.com/alifazelidehkordi/pdf-to-markdown-skill). Навык устанавливается в каталог Codex; исходники конвертера не скопированы в публичный курс. Для повторного преобразования служат `tools/convert_books.py` и `tools/run_pdf_skill.py`.

Полные книги, извлечённые страницы и изображения находятся **только локально** в `Literature/converted/` и исключены из Git. Публикуются библиографическая карта, статистика покрытия и авторское изложение в `Module_theory`.

## Что получено

Каждый каталог `converted/book_XX/` содержит:

- `book.md` — структурированное извлечение с маркерами исходных PDF-страниц и относительными ссылками на рисунки;
- `book_images/` — извлечённые изображения с короткими переносимыми именами;
- `pages/` — JPG-факсимиле всех страниц, сохраняющие видимые формулы, векторные схемы и таблицы независимо от качества извлечения;
- `visual-index.md` — Markdown с изображением каждой страницы;
- `manifest.json` — инвентаризация страниц, рисунков, векторных объектов и hash исходного PDF;
- `conversion.log` — предупреждения выбранного движка.

Текст содержит ссылку на визуальный оригинал после каждой страницы. Извлечённая иллюстрация не всегда совпадает с одним логическим рисунком: схема может быть собрана из нескольких PDF-объектов. Поэтому именно постраничные факсимиле сохраняют полный визуальный контекст. Формулы не объявлены автоматически восстановленными в LaTeX.

Использован PyMuPDF4LLM 2.1 в legacy layout для локального текста и изображений. Этот режим **не выполняет OCR**: параметр `use_ocr` встроенного скрипта игнорируется движком, что явно записано в логах. Текст внутри сканированных изображений может остаться только на картинке. Все страницы при этом визуально сохранены; их распознавание — отдельная операция, не скрытая под словом «извлечено».

Результат: 2657 маркеров страниц, 767 ссылок на отдельные изображения, 2657 факсимиле. Проверка относительных ссылок после нормализации имён не обнаружила отсутствующих рисунков. Статистика по книгам — [conversion-summary.json](conversion-summary.json).

## Как повторить

Установить навык по инструкции его репозитория, затем в отдельной среде установить `pymupdf4llm==2.1` и выполнить из корня курса:

```text
python tools/convert_books.py --legacy-layout --workers 2
```

Скрипт сохраняет исходные PDF, не перезаписывает существующий результат конвертера и нормализует ссылки. Для намеренной новой конвертации выберите новый каталог/перенесите прежний результат; не удаляйте книги. Размер визуальной библиотеки значительно больше текстового курса. Полная конвертация не означает, что каждый абзац книги прошёл экспертную вычитку.

Как именно источники связаны с главами — в [карте чтения](READING_MAP.md).
