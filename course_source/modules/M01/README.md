# Модуль 1 — как из наблюдений перейти к научному решению

**Статус:** педагогический пилот двухблокнотного стандарта; НЕ проверено на поддерживаемой матрице ОС и версиях, НЕ опубликовано на Stepik.
**Длительность:** ориентир 40–60 минут разбора + 60–90 минут самостоятельной лабораторной; уточняется пилотом.

## Научная история

Исследователь материалов изучает, как температура термообработки и доля добавки влияют на условную прочность покрытия. Первое предположение — температура улучшает прочность независимо от состава. Четыре результата 2×2 показывают, что это слишком простое объяснение: эффект меняется в зависимости от второго фактора. Но и «идеально подогнанная» модель на четырёх точках без повторов не доказывает устойчивости результата.

Это педагогическая ситуация с **синтетическими** данными; химический механизм и реальные свойства материала здесь не утверждаются.

## Маршрут

1. Начните с [инструкции по окружению](../../SETUP_WINDOWS_LINUX.md).
2. Пройдите **[01_guided_case.ipynb](01_guided_case.ipynb)**: наблюдения → условные эффекты → факторные эффекты → визуализация → насыщенная модель → ограничения → предложение следующего эксперимента.
3. Выполните **[02_independent_lab.ipynb](02_independent_lab.ipynb)**: новый материал → самостоятельный расчёт/график → конфликт единиц → предложение нового плана измерений.
4. Сдайте интерпретацию и обоснование, не только числа. Из самостоятельной работы должен получиться короткий отчёт: гипотеза, данные, метод, численный результат, график, научная оговорка, проект нового эксперимента.
5. Дополните междисциплинарную концептуальную карту отношениями между фактором, откликом, статистической моделью и экспериментальной проверкой.

## Что студент должен уметь после модуля

- Отличать наблюдение от статистической модели и экспериментального доказательства.
- Объяснять смысл взаимодействия двух факторов без апелляции к p-value, которого здесь нельзя надёжно определить.
- Считать эффекты из 2×2 таблицы, понимать разницу между эффектом AB и разностью условных эффектов.
- Обнаруживать смешение МПа и кПа; сохранить исходные данные и исправленный столбец.
- Делать график взаимодействия и интерпретировать физический смысл осей/единиц.
- Описать, каких дополнительных опытов не хватает для вывода о воспроизводимости.

## Критические ограничения

- Без повторов в насыщенном плане нет независимой оценки остаточной ошибки.
- Зависимость фактора от другого в четырёх синтетических точках не является доказательством химического механизма, оптимального промышленного режима или значимого эффекта в реальной популяции.
- Приход одного CSV с теми же числами не означает независимую репликацию.
- Перед публикацией требуется научная, техническая, методическая и пользовательская проверка.

## Проверка автором курса

Проверка структуры (нужен пакет nbformat):

```sh
python -m unittest discover -s course_source/modules/M01/tests -p "test_*.py" -v
```

Проверка исполнения Jupyter-ядром (нужны ipykernel, nbclient, matplotlib):

```sh
RUN_NOTEBOOK_EXECUTION=1 python -m unittest discover -s course_source/modules/M01/tests -p "test_*.py" -v
```

Для Windows PowerShell перед командой `$env:RUN_NOTEBOOK_EXECUTION="1"`; после теста `Remove-Item Env:RUN_NOTEBOOK_EXECUTION`. Тесты, запускаемые вне репозитория, работают в отдельном временном каталоге.

Эти проверки пока лишь разработаны и **не являются свидетельством прохождения**, пока реальный запуск с логами не будет выполнен в целевой среде.
