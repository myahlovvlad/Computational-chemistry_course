# Модель: растворённая форма, равновесие и измерение

Для слабого основания при одной нейтральной твёрдой фазе и подходящих activity assumptions S=S0(1+10^(pKa−pH)); для кислоты знак меняется: S=S0(1+10^(pH−pKa)). Эти модели не учитывают автоматически сольваты, соли, ионные пары, комплексирование, разложение и неполное равновесие. Intrinsic S0 относится к нейтральному виду и выбранной твёрдой фазе, а не любому baseline при произвольном pH.

Table 2 истрадефиллина при 293.15 K содержит 0.10–0.41 µg/mL. 1 µg/mL=1 mg/L=0.001 g/L. Для API equivalents c=(S·0.001)/384.43 mol/L. Это выбор молекулярной основы, не масса гидрата/сольвата. Условия калибровки источника требуют проверки: stated range 0.001–0.1 mg/mL выше всей aqueous-таблицы без отдельного концентрирования/калибровки. Неизвестные LOQ/raw details не выдумываются.

При диагностически выбранном S0 выражение pH+log10(S/S0−1) должно быть постоянным для идеальной модели основания. Если S≤S0, выражение не определено; epsilon не исправляет физическую неопределённость. Несогласие может отражать модель, фазу или измерение; оно не даёт новой измеренной pKa.

В B Table 11 сообщает baseline 0.000270 M при pH 6.9, K и CE для двух CD. Это не доказанное neutral-species S0 и не печёночная концентрация.
