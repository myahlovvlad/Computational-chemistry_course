# Модуль 10: Реальный redocking 1IEP

## Сущность и назначение

Выполнить официальный пример Vina и сравнить геометрию с подготовленным лигандом.

## Данные и workflow

Открытые 1IEP PDBQT/SDF, box и официальный выход; upstream commit и hash — в docking/provenance.json.

Проверка данных → box → Vina seed42/cpu1 → mapped RMSD → интерпретация.

[Паспорт данных](../datasets/README.md); [установка](../SETUP.md).

## Два этапа работы

1. [Разбор кейсов и кода](../notebooks/lab10.ipynb): пояснение → короткая ячейка → интерпретация.
2. [Самостоятельные кейсы](../notebooks/lab10_practice.ipynb): три условия, входы, места для собственного решения, проверки и рубрика.

Полный Vina run обязателен: argv, новые позы и logs, конечные score/RMSD. Без бинарника BLOCKED; значения seed42 не являются универсальным эталоном.

Исторический benchmark относится к прежней редакции. Свежие результаты парного формата публикуются отдельно в paired-execution.json. Пустые задания имеют NOT_RUN, даже если notebook запускается без ошибок.

[Ключ преподавателя](../solutions/lab10.md). Приложения создаются и отлаживаются в [IDE](../ide/README.md).
