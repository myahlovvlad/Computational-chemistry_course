# Введение в хемоинформатику и вычислительную химию: «Операция Химера»

> Эта папка сохраняет предыдущую редакцию. Действующая углублённая теория находится в [Module_theory](../Module_theory/README.md), полный проверенный практикум — в [Labs](../Labs/README.md). Сведения о готовности в старых документах ниже относятся к предыдущему этапу.

**Редакция:** 10 ноября 2026. **Автор и аффилиация:** заполняются владельцем курса перед публикацией; сведения не вымышлены.

Лаборатории нужен обоснованный список соединений для следующего эксперимента. Вычислительный результат поможет только тогда, когда понятны происхождение данных, ограничения метода и способ проверки. В этом курсе мы собираем локальный конвейер на Python/RDKit, учимся проверять прогнозы и передаём результат коллеге в понятном отчёте.

Это редакторский пакет для переноса в Stepik: программа, тексты всех 14 модулей, разобранные кейсы, задания, сценарии видео и небольшой работающий интерактив. Исходные материалы сохранены. Курс в аккаунте Stepik не создавался. Тексты модулей — новая согласованная редакция, а не автоматическая правка исходных черновиков.

Начните с [разбора проекта](01_AUDIT.md), затем откройте [программу](02_PROGRAM.md). [Сценарий переноса](03_STEPIK.md) объясняет, какие части текста становятся шагами. [Кейсы](04_CASES.md) содержат условия, ход решения, ответы и критерии оценки. [Интерактив и видео](05_MEDIA.md) привязаны к конкретным урокам. [Источники](06_SOURCES.md) отделяют проверенную документацию от исходных библиографических набросков. [Проверка пакета](07_VALIDATION.md) описывает фактически выполненные проверки и оставшуюся подготовку.

Для первого запуска ноутбука можно использовать Jupyter; Colab — добровольный вариант только для открытых учебных данных. Основной маршрут остаётся локальным.
