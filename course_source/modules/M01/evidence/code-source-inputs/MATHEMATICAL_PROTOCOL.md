# M01. Математическая постановка и правила интерпретации

Этот протокол — опора для [разбора](01_guided_case.ipynb) и [самостоятельной работы](02_independent_lab.ipynb), а не новая опубликованная модель растворимости. [Обозначения и сокращения](GLOSSARY.md), [источник данных](RESEARCH_SOURCE.md).

## Научный вопрос и объект

Достаточно ли малой средней ошибки готовых архивных прогнозов, чтобы считать каждый из них надёжным для планирования проверки растворимости? Объект анализа — пары наблюдение/прогноз в конкретном CSV DeepChem. Цель расчёта — описать общее и локальное несоответствие, а не доказать причину отклонения или обучить новую модель.

В [работе Delaney](https://pubmed.ncbi.nlm.nih.gov/15154768/) рассматривается оценивание водной растворимости из молекулярных свойств. Наш [вторичный snapshot](https://github.com/deepchem/deepchem/blob/455d07f3e17e880a4d980b5b0365e4a02b417e14/datasets/delaney-processed.csv) не является полным набором оригинального исследования. Происхождение готового predicted-столбца не позволяет объявить наш расчёт независимой проверкой модели на новых объектах.

## Физическая величина, модель и наблюдение

Растворимость описывает состав насыщенного раствора; используемая величина должна сопровождаться определением растворителя, формы и условий. [IUPAC, solubility](https://goldbook.iupac.org/terms/view/S05740/1000). В данной задаче запись имеет вид

$$
y_i=\log_{10}\left(S_i/(1\;\mathrm{mol\,L^{-1}})\right),\qquad S_i>0.
$$

Для концептуального разделения причин введём физическую зависимость $g$, условия $u_i$ и неопределённость наблюдения $\eta_i$: $y_i=g(x_i,u_i)+\eta_i$. Это схема рассуждения, не подобранная функция и не предположение о распределении шума. Неизвестные условия не идентифицируются из одной пары чисел.

Вычислительная модель записывается $\widehat y_i=f_\theta(\phi(x_i))$. Линейная регрессионная форма класса таких моделей — $\beta_0+\sum_j\beta_j\phi_j(x_i)$; конкретные коэффициенты оригинальной ESOL здесь не восстанавливаются. В коде используется уже предоставленный столбец, а не эта символическая запись для нового обучения.

## Данные и начальные условия

$D=\{(i,\mathrm{name}_i,\mathrm{SMILES}_i,y_i,\widehat y_i)\}_{i=0}^{1127}$. `row_id` — нулевой номер строки, не химический ID. Определены учебные множества $I_G=\{i:i\bmod4=0\}$, $I_L=\{i:i\bmod4=1\}$, по 282 записи. Они не пересекаются по номеру строки; химическая независимость и независимость от обучения этим не доказаны.

До расчёта проверяются версия и SHA256, названия колонок, число строк, конечность чисел и соответствие пар. Raw не перезаписывается. Температура, pH, твёрдая форма и индивидуальная неопределённость измерений в CSV отсутствуют. Значения 25 °C, pH 7, вид формы и другие удобные условия **не являются входными данными** и не добавляются по умолчанию.

## Что здесь означает граница задачи

У табличного анализа нет пространственных граничных значений, как у краевой задачи дифференциального уравнения. Есть область определённости преобразования $S>0$, состав входа и границы интерпретации. Для будущего физического эксперимента условия обязаны быть заданы и зарегистрированы отдельно; неизвестные условия прошлых наблюдений нельзя заменить плановыми условиями будущих.

Идентифицируемые результаты: значения метрик и конкретные расхождения в этом архиве. Неидентифицируемые по предоставленному входу: причинный механизм расхождения, неопределённость отдельного измерения, независимая будущая точность, BBB-проницаемость, связывание с рецептором и клеточная экспозиция.

## Вычислительные определения и интерпретация

Для заранее выделенного множества $I$, $n=|I|$:

$$
e_i=\widehat y_i-y_i;\quad
\mathrm{MAE}=\frac1n\sum_{i\in I}|e_i|;\quad
\mathrm{RMSE}=\sqrt{\frac1n\sum_{i\in I}e_i^2};\quad
i^*=\arg\max_{i\in I}|e_i|.
$$

$e_i>0$ — завышение прогноза; $e_i<0$ — занижение. $10^{e_i}=\widehat S_i/S_i$, $F_i=10^{|e_i|}$. MAE/RMSE имеют логарифмическую шкалу, $F_i$ — безразмерная кратность. $10^{\mathrm{MAE}}$ — геометрическое среднее кратностей, не верхняя граница и не средняя абсолютная ошибка в mol/L. Отношение рассчитано из архивных значений, а не независимо измерено в notebook.

Для явно **учебного** ориентира `factor_limit = 10`:

$$
\tau=\log_{10}(10)=1,\quad C_\tau=\frac1n\sum_{i\in I}\mathbf1(|e_i|\le\tau),\quad
J_\tau=\{i\in I:|e_i|>\tau\}.
$$

Граница включается в долю Cτ; записи Jτ подлежат отдельному разбору относительно выбранного ориентира. Значения 10 и 1 не заимствованы как химический норматив, критерий статьи или требование к лекарству. Cτ — описательная доля архива, не вероятность будущего успеха. Смена ориентира меняет вопрос, а не численное качество тех же прогнозов.

## Критерии приёмки

| Уровень | Наблюдаемое свидетельство | Что ещё не доказано |
|---|---|---|
| Целостность входа | Совпали SHA256, schema, n; сохранены пары и ID | Истинность первичного химического измерения |
| Правильность операции | Верный знак/шкала; конечные значения; 0 ≤ MAE ≤ RMSE; F ≥ 1 | Химическая пригодность модели |
| Описание расхождения | Все записи, график, метрики, ориентир и крупнейший остаток | Причина отклонения |
| Научное решение | Вывод ограничен данными; названы альтернативы и различающая проверка | Результат ещё не выполненного опыта |
| Перенос навыка | Собственный код, диагностика C2, аргументированный план C3 | Образовательная эффективность для всех учащихся |

Численные эталоны из существующей версии не изменяются ради прохождения. Допуск сравнения float в проверках — вычислительная техническая величина, не физическая погрешность опыта.

## Концептуальный и вычислительный workflow

```text
Предмет:   потребность в растворе → вопрос о свойстве → сравнение свидетельств → план проверки
Математика: определения/условия → пары y, ŷ → остатки/кратности → описание и границы вывода
Код:       SHA/schema → фиксированная часть → residual table → metrics/plots → audit → dossier
```

Метод выбирается по вопросу. Сравнение готовых пар требует арифметики и визуализации; новое обучение не объясняет автоматически ошибку архива. Неизвестная физическая переменная требует источника или подходящего измерения, а не дополнительной строки Python.
