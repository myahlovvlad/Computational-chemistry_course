# Формы и политика идентичности

Равенство формулы не задаёт равенства связности. Изомеры могут иметь один элементный состав и разное расположение связей. Изменение протонирования меняет число H и заряд; образование лактонного цикла меняет ковалентную связность. Нейтрализация — определённая операция над графом, а не универсальное исправление любой формы вещества.

Соль в выбранной записи представлена несколькими несвязанными фрагментами. Формальный заряд всей записи равен сумме зарядов фрагментов: $Q=\sum_j q_j$. Для записи кальциевой соли из этого набора есть два органических аниона и Ca²⁺, поэтому $Q=(-1)+(-1)+2=0$. Нулевой суммарный заряд не делает запись одной нейтральной ковалентной молекулой.

Начальные условия: берём конкретные исходные SMILES без удаления фрагментов. Отдельно сохраняем заряды, число компонентов и формулу. Если формируем parent-представление, называем цель, операцию и потерянные сведения. Выбор крупнейшего фрагмента сам по себе теряет количество эквивалентов и противоион.

В дальнейшем для условной стехиометрической задачи используем $n_{active}=2m_{salt}/M_{salt}$ только для идеальной безводной записи с двумя активными анионами. В реальной навеске нужны данные о гидратации, чистоте и принятой основе количественного содержания. Этот урок их не устанавливает и не является инструкцией приготовления лекарственного препарата.

Приёмка: исходник сохраняется; сравнения явно указывают форму/заряд/связность; равная масса не объявляется тождеством; предполагаемое химическое превращение не подменяется строковой нормализацией. Базовые определения — в [словаре курса](../../../../glossary.md).
